# CTA strategy factory quarantine focused fixture

Run from the repository root:

```sh
src/TestUnits/fixtures/cta_factory_quarantine/run.sh /private/tmp/cta-factory-quarantine
```

The script requires a C++17 compiler, Perl, Git and physical Boost, fmt and spdlog include directories. The default include paths point to this machine's Homebrew Cellar; `WT_BOOST_INCLUDE`, `WT_FMT_INCLUDE` and `WT_SPDLOG_INCLUDE` override them. It uses a fresh `mktemp` child directory, writes no symbolic links, builds the current manager and real fake dynamic libraries, and records raw per-case output, commands and source hashes. `logger_stub.cpp` enables the real `WTSLogger` template and `fmtutil` formatting path but supplies the output sink and logger static state; it does **not** test the complete logging backend or the C API.

Current cases cover creator and name exceptions, null and empty factory values, repeated scans, same-name factories from different modules and managers, retry after quarantine, successful loading of another module after failure, same-handle reentry and a path alias under concurrent load, one `getName` call, and healthy strategy creation/deletion. Two 4097-byte names sharing the same 4096-byte prefix verify full identities remain distinct while only bounded names reach the formatting path. Short and real deep directories verify logging does not change the filesystem path; a 4097-byte nonexistent input exercises the error diagnostic. A separate module with no factory export starts a background worker during static initialization; the test checks that repeated scans keep this worker and module alive. An independent preload observes unload/factory-destruction markers; the extra reference is dropped before checking. The historical `HEAD` build supplies six negative controls and a healthy positive control. `HEAD` is **not** the previously dirty workspace snapshot, so these are historical controls rather than proof that every issue was dynamically reproduced immediately before this change. When `WT_CTA_PREVIOUS_SOURCE` points to the saved pre-review candidate, four additional controls demonstrate the repeat-scan, no-export, long-name and cross-manager conflict failures. `WT_CTA_PATH_PREVIOUS_SOURCE` can additionally select a saved pre-path-fix source for the short-path positive and two path-display negatives.

For a focused ASan comparison, use `run_path_asan.sh <output-dir> <pre-path-fix-CtaStrategyMgr.cpp>`. The executable, manager and fake plugin are compiled with ASan, but the logger output sink remains a stub. Leak checking is disabled because the quarantine intentionally retains objects and modules. This checks only the selected path cases; it does not validate the complete real logger.

The runtime registry deliberately retains failed factory objects and one loader reference until process exit. A module with no creator export is ignored for registration as before but is also retained, including any work started during its initialization; each distinct such module consumes a loader reference until exit. A name conflict is local to the manager, while its unregistered object and module reference remain retained; another manager may still instantiate that healthy module. The plugin ABI does not guarantee that multiple factory instances are safe. Each independently loaded copy of the manager translation unit has its own registry; unloading and reloading the containing module or loading another copy can lose access to a quarantined record. No plugin function runs while its registry or factory-table mutex is held. Different manager instances using the same registry and attempting an in-progress module receive a failure instead of waiting; a healthy module can be loaded later. This fixture does not prove real third-party behavior, C API integration, Windows, Linux, shutdown or unload safety, the lifetime of wrappers beyond their manager, arbitrary concurrent access to the strategy map, nor static initialization performed inside `dlopen` before a handle is available. It does not validate other logger users or run a full regression.
