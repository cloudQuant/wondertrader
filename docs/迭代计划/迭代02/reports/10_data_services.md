- r5_udp_caster_test.cpp:123-125 将不支持 type 3/99 断言成功；应为失败并验证状态不变。146-149 把负端口断言成功，应拒绝 -1/65536，保留 0/65535。

- R54-002 禁用测试直接调 UftStraContext，绕过 parser fallback；应走 parser→ticker→engine→context。
- R5-009 用例只看 initialize/ORIGINAL，不能观察 _sections；午夜合法性待合同确认，2400 可是半开区间终点。

- R8-006 重入失败后期待 pa_second 是现状断言；修复应保持首次 ID，另有 _cfg retain 未释放的确定子项。

- R18-001、R44-002/006/008、R68-001 是直接传 null 的前置条件问题；R44-007 的 init 前生命周期也待合同。
