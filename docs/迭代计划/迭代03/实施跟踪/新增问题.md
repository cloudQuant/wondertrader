## I03-NEW-001：TraderMocker 拆量非法配置导致不终止或无效区间

- 状态：本机定向通过；发现于 BUG-R113-002 定向开发的静态审查，整体回归未运行。
- 位置：`src/TraderMocker/TraderMocker.cpp` 的 `init`、`match_once` 和 `splitVolumeWithRng`。
- 证据：`init` 对浮点 `minqty/maxqty` 只将等于 0 的值替换为默认值，撮合时转成无符号整数；例如两者均为 0.5 时会转换为 0，拆分逻辑 `curVol == 0` 时继续循环，可能不终止。逆序和无符号长度溢出输入也需要界定合法合同。
- 修复：在设置种子、字段和创建目录之前校验转换区间；保留既有近零默认值和合法数量的整数截断语义，非法配置返回失败并输出诊断。自由函数遇到无效整数区间返回空结果，避免死循环及除零。
- 验证：修改前配置负控失败，非法区间用例经 3 秒有界运行超时；修改后 12 个相关定向用例通过，包含合法、非法、默认、固定种子和真实撮合对照，见 [证据](evidence/I03-NEW-001/)。其他依赖复用 v8 构建；完整工作树、其他平台和整体回归未验收。
