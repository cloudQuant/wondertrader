# BUG-L04-004 合同导入宽度子项

合同文件载入在注册或自动创建 rules 商品前检查交易所 <16、代码 <32 字节；合法 15/31 和混合无效输入可追溯。主代理在独立 TMPDIR 重新运行当前产品对象：相关 2/2 PASS；以当前源码移除新判断的隔离基线运行同一新用例失败（两个 XML）。构建脚本、日志、哈希和探针在本目录；其他库复用 v8 构建，并非完整当前树。

直接 `LMDBHftKey`/`LMDBBarKey` 仍无界 strcpy。额外头文件探针显示 16 字节交易所或 32 字节代码可破坏字段内 NUL，单靠 ASan 没有报错不能证明安全。AD 各 reader/writer 及缓存、异步队列尚需完整失败传播，须保持 key 布局 ABI；因此本项仍 BLOCKED。其他平台和整体回归未验。
