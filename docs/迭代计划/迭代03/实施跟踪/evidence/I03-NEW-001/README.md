# I03-NEW-001 非法拆量范围定向证据

R113-002 的 follow-up：init 在创建目录、设置种子和配置字段前拒绝无法安全转换为非零 uint32 区间的配置，保留既有 decimal::eq 近零默认值及截断后仍合法的区间。旧 splitVolume 自由函数对无效整数区间返回空向量，避免无进度循环和除零。

当前相关源码独立重编，完整编译/链接命令与源码哈希在 `build.log`；12 个关联单例均 exit 0、XML 无失败（`i03_001_run0` 至 `i03_001_run11`）。修复前对象的非法配置用例 exit 1，非法拆量用例在 3 秒超时，见 `i03_001_red_results.json`。其中包括对 BUG-R113-002 的直接相关复验。

macOS arm64；其他依赖复用 v8 的库和对象，未证明当前完整树。Windows、跨平台、整体回归未运行。自由函数此前无非法参数的公开返回合同，当前空向量为显式失败结果；生产 init 在输入到达拆量前拒绝该类配置。
