## 已复核的行为

费用格式支持合约优先、品种回退，缺失报错，显式零有效。实际行情在订阅码覆盖前核验物理身份，getter保留同一事件来源，金额计算采用实际合约乘数。初始化保留金额费率缺元数据拒绝；真正开始重载后失败使费用表失效，运行中拒绝重载保留旧表。首个费用错误停止回放并保留，失败初始化不会清掉旧错误。

CTA/SEL在交易账本写入前预检全部费用段，失败保留信号。HFT/UFT在整轮拆分前预检费用，以作用域回执确认虚回调是否真正提交；Exp只对已提交成交发通知。回调在提交后抛异常时保留已成交结果并扣减对应余量；回调改写持仓或订单状态时停止后续分笔并保留观察结果，未实现自动对账。费用预检不承诺用户回调异常、OOM或日志I/O失败时整轮回滚。

Local/Arbi支持有序组数组；旧对象格式的重叠组需要显式完整 `group_order`。带符号/小数配方按序分解，显式组参与物理净目标，组限额检查缩放后目标；校验期间账本版本变化则整批拒绝。有效批次先提交账本和预排队列，再在锁外调用执行单元。

配置加载器在构造返回Variant前拒绝原始或解码后的NUL键/字符串；Unicode、普通转义及YAML语法异常原合同保留。没有借此改变null丢弃或重复键覆盖行为。
