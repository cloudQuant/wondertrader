# T26-007 费用文件的完整性与失败处理

2026-11-02，macOS arm64。针对 CTPLoader 的候选修复和独立定向证据；不连接真实 CTP 或交易。**不构成 T26-011 或供应商回报完整性验收。**

`DumpFees()` 先按当前合约、筛选条件、保证金和费率表建立完整结果：有缺失、非有限数字、CTP 的 `DBL_MAX`/`FLT_MAX` 缺失哨兵、空身份、冲突别名、重复保证金或相同合约不同费率时拒绝发布；显式零值及有限负值保留。佣金六个字段须均为有效值：单一 `byvolume` 文件格式无法表达金额与按手的混合，任一费用有两种非零成分即拒绝；纯金额微小非零值不再按旧 EPS 静默转零，全零沿用按量模式。保证金四个字段须均有效、按手部分为零，且多空金额比例相等，否则单一 margin 无法无损表示而拒绝。`WTSContractInfo.hpp` 的 `getLongMarginRatio` 和 `getShortMarginRatio` 在 commodity margin 非零时都会使用这个单一费率。错误佣金/保证金回调在本实例锁存，后续正常回调不能把已观察到的错误当成功。终局 `DumpFees` 失败或当前已观察到回调错误时进程退出码为 1。成功时仍使用原 JSON 字段和键；支持交易所代码、规范代码和原始 altcode 的唯一关联，以及产品费率回退。增量加载后的同身份重复合约缓存允许合并，不同身份共用别名则拒绝。为保守处理潜在别名冲突，即使 `SET_FILTERS` 排除该合约，未选择合约的无效身份仍会拒绝整次发布；这是明确的兼容性收紧。

费用 JSON 在目标目录用独占临时文件写入，检查写入、flush 和 close，成功后替换目标；失败时尝试移除临时文件并保留旧费用文件。POSIX 已有目标须是当前用户持有且可写的普通文件，保留普通权限位和组；不跟随目标符号链接。对于由其他用户拥有但当前用户有写权限的文件，旧 `ofstream` 可能成功而新实现拒绝替换，这是兼容性收紧。使用相同目录的原子 rename，但**不承诺多文件事务或断电持久性**：未 fsync 文件/目录，非合作进程可并发改变路径，ACL/扩展属性和硬链接兼容未证明。Windows 代码采用 `ReplaceFileA` / `MoveFileExA`，没有实机或交叉编译验证，其 ACL、路径和替换语义仍待单独验收。错误时旧文件可能是过期数据，使用方必须检查退出状态，不能仅因旧文件存在就视为本次成功。现有 `DumpToJson()` 在费用发布前执行，合约/品种文件不能与费用文件视为一个事务，其独立写失败也不由本修复覆盖。

当前终局仍用 `IsQueryQueueEmpty()`，队列为空并不证明所有 SDK 请求回报完成；已观察到的回调错误锁存不能捕获尚未到达的回调。回调映射本身的并发与复用合同、厂商断连和迟到帧也未证明。`CTraderSpi` 新增原子字段，引用其布局的程序须重编；现有全局费率/保证金表的多实例隔离并未解决。禁止将本文中的检查理解为真实供应商查询完整性或 T26-011 已修复。
