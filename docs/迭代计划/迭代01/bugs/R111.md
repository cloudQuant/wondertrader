# R111 疑似缺陷登记（状态：待审核，未修改源码）

Lane: R111（第十九波），靶子 `ExecMocker/CtaMocker/UftMocker/HftMocker/SelMocker/HisDataReplayer`。
以下问题由测试夹具设计与源码对读发现，**未对 `src/**` 做任何修改**。行号以当前 HEAD 为准。

后续隔离观察：为评估 R20 的执行器初始化夹具，单独运行现有 `R111ExecMocker.InitWithRealExecuterAndInitSchedule`，本机进程 signal 11，尚无因果栈或具体崩溃阶段。R111 没有按正常 runner 顺序注册 sink 并 prepare，手动派发的事件时间也与回放区间不一致；执行工厂删除函数的静态 ABI 不匹配已归入 BUG-R190-001。该控制未能建立安全夹具，不是下述未知策略名缺陷的复现，也不证明崩溃必然由任何一个特定原因导致。

## BUG-R111-001 Mocker 策略工厂在策略名不存在时解引用空 `_strategy`（状态：待审核）

- 编号: BUG-R111-001
- 模块/文件/行:
  - 代表路径：`src/WtBtCore/SelMocker.cpp:261-267`（`init_sel_factory`）
  - 同构路径：`src/WtBtCore/UftMocker.cpp:163-164`、`src/WtBtCore/HftMocker.cpp:248-249`、
    `src/WtBtCore/CtaMocker.cpp:442-447`
- 现象（源码静态分析，动态未复现）:
  - `_strategy = _factory._fact->createStrategy(cfgStra->getCString("name"), id);`
  - Sel/Cta 只在 `if (_strategy)` 里打日志，随后**无条件**执行
    `_strategy->init(...)` / `_strategy->id()`；Uft/Hft 连日志判断都没有。
  - 插件工厂明确对未知策略名返回 NULL（如 `WtSelStraFact::createStrategy`、
    `WtStraFact::createStrategy`），调用方没有检查空值，进入未定义行为路径。
- 输入/前置条件:
  - 插件模块存在且导出 `create*StrategyFact`（本机构建产物即可）；
  - 配置 `strategy.name` 写成工厂不认识的名称，例如：
    ```json
    { "module": "<bin>/libWtCtaStraFact.dylib",
      "strategy": { "name": "NoSuchStrategy", "id": "x", "params": {} } }
    ```
  - 调用 `CtaMocker::init_cta_factory(cfg)` / `UftMocker::init_uft_factory(cfg)` /
    `HftMocker::init_hft_factory(cfg)` / `SelMocker::init_sel_factory(cfg)`。
- 期望:
  - `createStrategy` 返回 NULL 时记录错误并返回 false（或至少跳过策略初始化），
    与同族 `*StrategyMgr` 的修复口径一致（BUG-R82-002 / BUG-R104-004 已记录管理器侧同类问题）。
- 实际（静态）:
  - 若工厂成功加载并创建，但策略名不受支持，`createStrategy()` 返回 NULL，随后
    `_strategy->init(...)`/`_strategy->id()` 被无条件调用。此处为未定义行为，常见实现可能崩溃，
    但本轮没有动态触发，不能声称必然 SIGSEGV 或给出未取得的崩溃栈。
- 复现步骤:
  1. 用上述配置构造对应 Mocker（`HisDataReplayer` 可为空构造）；
  2. 调用对应的 `init_*_factory`；
  3. 本轮没有执行此输入。现有 R111 插件测试使用支持的策略名（CTA `DualThrust`、UFT
     `SimpleUft`），不能证明未知名路径的运行结果；应增加安全的返回值断言测试。
- 严重级别: Major 候选（错误策略名触发未定义行为；具体崩溃结果未动态验证；与 R82/R104 同族）
- 测试处理:
  - 本轮启用用例只使用合法策略名（DualThrust / SimpleUft），不触发该路径；
  - 未新增 `DISABLED_` 用例（会直接 SIGSEGV，且与既有 R82/R104 缺陷族重复度高），
    仅登记待审核。

## 与既有缺陷的关系（不重复立案）

- `UftMocker` 会话回调/成交回写对 `_strategy`、`commInfo` 的空指针族：
  BUG-P08-001 / BUG-P08-006；`UftMocker::stra_enum_position` 无策略崩溃：
  BUG-R72-001。本 lane 的策略非空用例不触碰这些路径。
- `UftMocker` 的 `PosInfo→PosItem` 强转、0 量明细残留：BUG-P08-002 / BUG-P08-003。
- `UftMocker::stra_cancel_all` 恒返回空：BUG-P08-004。
- `HftMocker` 按量撤单 qty=0 只撤一笔：BUG-P08-007。
- `CtaMocker` 的 `tdate/settime`、增量 dump 字段：BUG-Q02-001 / BUG-Q02-003。
- `SelMocker::handle_replay_done` 零调度除零：BUG-Q02-002。
- `ExecMocker` 的 `_exec_unit/_last_tick` 空指针族：BUG-N04-001（n04 清单）、
  R20 的 `DISABLED_ExecUnitNullDerefFamily`。

本 lane 的 12 条启用用例均避开上述缺陷输入；若主控运行出现非预期崩溃，
优先按以上既有编号归因。

## 本轮独立复核裁定（2026-10-29）

| 裁定 | 源码/测试证据 | 修复与边界 |
|---|---|---|
| **条件明确的产品缺陷候选；动态待证，不是测试误报。** | Mocker 调用链在 `SelMocker.cpp:261-270`、`CtaMocker.cpp:442-451`、`UftMocker.cpp:163-164`、`HftMocker.cpp:248-255` 里均对策略返回值无空值保护。工厂契约明确未知名返回 NULL：`WtSelStraFact.cpp:69-76`、`WtCtaStraFact.cpp:88-94`、`WtUftStraFact.cpp:100-109`、`WtHftStraFact.cpp:91-100`。既有 R111 plugin 测试使用已支持名称，未覆盖错误名；本轮未运行会进入 UB 的输入。 | 每个 factory init 先检查 factory creator 和 `createStrategy` 结果，空值记录明确错误并返回 false，避免 `init/id` 调用；增加可加载真实工厂、未知策略名并断言 init 失败的回归用例（可按 mocker 参数化覆盖）。 |
