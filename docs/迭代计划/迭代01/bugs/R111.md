## BUG-R111-001 Mocker 策略工厂在策略名不存在时解引用空 `_strategy`（状态：待审核）

- 编号: BUG-R111-001
- 模块/文件/行:
  - 代表路径：`src/WtBtCore/SelMocker.cpp:261-267`（`init_sel_factory`）
  - 同构路径：`src/WtBtCore/UftMocker.cpp:163-164`、`src/WtBtCore/HftMocker.cpp:248-249`、
    `src/WtBtCore/CtaMocker.cpp:442-447`
- 现象:
  - `_strategy = _factory._fact->createStrategy(cfgStra->getCString("name"), id);`
  - Sel/Cta 只在 `if (_strategy)` 里打日志，随后**无条件**执行
    `_strategy->init(...)` / `_strategy->id()`；Uft/Hft 连日志判断都没有。
  - 插件工厂对未知策略名返回 NULL（如 `WtSelStraFact::createStrategy`、
    `WtStraFact::createStrategy`），于是立即空指针解引用。
- 输入/前置条件:
  - 插件模块存在且导出 `create*StrategyFact`（本机构建产物即可）；
  - 配置 `strategy.name` 写成工厂不认识的名称，例如：
    ```json
    { "module": "<bin>/libWtCtaStraFact.dylib",
      "strategy": { "name": "NoSuchStrategy", "id": "x", "params": {} } }
    ```
  - 调用 `CtaMocker::init_cta_factory(cfg)` / `UftMocker::init_uft_factory(cfg)` /
    `HftMocker::init_hft_factory(cfg)` / `SelMocker::init_sel_factory(cfg)`。
- 期望:
  - `createStrategy` 返回 NULL 时记录错误并返回 false（或至少跳过策略初始化），
    与同族 `*StrategyMgr` 的修复口径一致（BUG-R82-002 / BUG-R104-004 已记录管理器侧同类问题）。
- 实际:
  - `_strategy->init(...)` 对空指针发起虚调用，进程 SIGSEGV；`SelMocker` 还会在
    日志后立刻崩溃，连 `_name` 都来不及设置。
- 复现步骤:
  1. 用上述配置构造对应 Mocker（`HisDataReplayer` 可为空构造）；
  2. 调用对应的 `init_*_factory`；
  3. 观察崩溃栈顶为 `ExecuteUnit/Strategy::init` 类的虚调用。
- 严重级别: Major（配置写错策略名即崩溃；与 R82/R104 的管理器侧缺陷同根）
- 测试处理:
  - 本轮启用用例只使用合法策略名（DualThrust / SimpleUft），不触发该路径；
  - 未新增 `DISABLED_` 用例（会直接 SIGSEGV，且与既有 R82/R104 缺陷族重复度高），
    仅登记待审核。
