## 新增缺陷

### BUG-R211-001 WtEngine::init 丢弃 init_riskmon 的失败，active 风控配置被静默忽略

- 位置: `src/WtCore/WtEngine.cpp:304-308`（`init_riskmon(cfgRisk);` 返回值未用）、
  `src/WtCore/WtEngine.cpp:1165-1171`（入口符号缺失时仅记日志并返回 false）
- 现象: 组合配置写了 `riskmon.active=true`，但 `module` 指向的合法 dylib 不导出
  `createRiskMonFact` 时，`init_riskmon` 释放模块并返回 false；`WtEngine::init`
  不检查返回值，引擎照常启动，`_risk_mon` 保持为空。交易侧没有任何可查询状态
  表明风控未生效，只有一行 `risk` 分类日志。
- 影响: 风控模块名写错、插件版本不匹配或目录混放时，组合会在“看起来启用了风控”
  的情况下裸奔；运行期也没有重试或告警升级。
- 复现: 见 `r211_wtcore_rest_test.cpp` 的
  `R211Engine.IncompatibleRiskMonModuleIsRejected`：`riskmon.module="WtExeFact"`
  （bin 下真实存在、可 dlopen、但无 `createRiskMonFact`），init 正常返回。
- 建议: `init` 在 `init_riskmon` 返回 false 时向上传递失败（或至少把
  `_risk_mon` 状态暴露为可查询并升级为 error/notify）；配置了 active 却装载失败
  不应等同于“未配置风控”。
- 状态: 待审核
