## 观察 1：WtDataReaderAD 刷新路径读取被 `std::move` 掏空的 LMDB 句柄

- 状态: 待审核
- 严重级别: Blocker（公开读取 API 空指针崩溃；命中分支事实不可达）
- 模块/文件:
  - `src/WtDataStorageAD/WtDataReaderAD.cpp:272-274`（`update_cache_from_lmdb` 无 `db == NULL` 检查）
  - `src/WtDataStorageAD/WtDataReaderAD.cpp:576-578`（`get_k_db` 命中时 `return std::move(it->second)`）
  - 调用点 `:444-456`（RT bar 越过 etime 的二次回源）、`:287-290`（同时间戳覆盖）
- 相关用例（R185 改 `DISABLED_`，输入与断言保留）:
  - `CoverageTests_adstorage` → `R172AdTest.R172ReaderADRtCacheBarAheadOfEtime`
  - `CoverageTests_adstorage` → `R172AdTest.R172ReaderADRtCacheBarPromotedToLmdb`
- 现象:
  1. `cacheBarsFromStorage` 首取 `get_k_db`（第 1 次）后槽位仍有效；
  2. 首读的 `update_cache_from_lmdb` 是第 2 次取句柄，`std::move` 把槽位掏空但返回值可用；
  3. 下一次刷新（Ahead 用例的首读内二次回源、Promoted 用例的第二次读）是第 3 次取句柄，
     得到空 `WtLMDBPtr`；`WtLMDBQuery query(*db)` 在 `WtLMDB.hpp:107-112` 调

- 期望: `get_k_db/get_t_db` 返回 `it->second`（拷贝）而非 `std::move`；`update_cache_from_lmdb`
  对空句柄判空返回。两者任一即可消除崩溃；建议都做。
- 影响: 同一 reader 对同一 (exchg, period) 的第二次刷新起随时空指针；`:444-456` 与
  `:287-290` 的 `_last_from_cache` 覆盖分支在公开 API 下不可达。
- 交叉引用: `bugs/R144.md` BUG-R144-002（同一根因、同一崩溃栈）、
  `bugs/p05_datastorage2.md` BUG-P05-001、`bugs/R4_adstorage.md` R4-BUG-02。
- 备注: 修复前 profdata 中 `:290`、`:451-455` 计数为 0，禁用不造成覆盖率回退；

## 观察 2：WtRdmDtReaderAD 首次载入把末笔覆写回首笔

- 状态: 待审核
- 严重级别: Blocker（静默数据损坏：切片首笔被换成末笔，常见输入返回 0 条）
- 模块/文件: `src/WtDataStorageAD/WtRdmDtReaderAD.cpp:135-144`（`readTickSliceByRange` 的
  `isEmpty` 分支，重点 `:137` 与 `:140`）
- 相关用例（R185 改 `DISABLED_`，输入与断言保留）:
  - `CoverageTests_adstorage` → `R172AdTest.R172RdmADTickRangeStartsAtFirstTick`
- 现象: `WTSTickStruct& curTs = tickList._ticks.front();` 之后执行
  `curTs = tickList._ticks.back();`。`curTs` 是指向 `_ticks[0]` 的引用，该赋值不是重新绑定，
  而是把末笔整体 `memcpy` 回首笔。R185 用 lldb 直读：LMDB 实际返回
  `[09:31:00, 09:32:00]` 两笔，载入后 `_ticks.size()==2` 且两笔 `action_time` 都是
  `93200000`；随后 `:232` 的首笔条件走 if 臂，`:236-247` 的第二次 lower_bound 不执行，
  `slice->size()==0`。
- 期望: `_ticks` 保持载入时的升序，首笔不被后续步骤改写。
- 影响: 所有「读区间再取子窗」的调用方拿到错位 tick；本次目标分支 `:236-247` 不可达。
- 交叉引用: `bugs/R32_adstorage.md` BUG-R32-001（同根因，R32 已取证 3 笔变
  `[末笔, 中间笔, 末笔]`）。
- 备注: 修复方向 `:140` 改为 `const WTSTickStruct& curTs = tickList._ticks.back();`（一行）。
  修复前 `:236-247` 计数为 0，禁用不造成覆盖率回退。
