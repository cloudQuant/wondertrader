## BUG-R131-001 CtaMocker::proc_tick 的 COND_ACTION_SP 分支缺 break（状态：待审核）

- 编号: BUG-R131-001
- 状态: 待审核
- 模块/文件/行:
  - `src/WtBtCore/CtaMocker.cpp:883-887`
  - `case COND_ACTION_SP:` 块在 `append_signal(...)` 后直接落入 `default: break;`
- 现象:
  - 其余 `COND_ACTION_OL/CL/OS/CS` 分支都以 `break;` 结束，只有 `COND_ACTION_SP`
    没有 `break`；当前 `default` 只有 `break`，所以**暂时没有可观察的行为差异**。
  - 一旦后续在 `default` 中补默认处理（例如记录未知 action / 统一清理），
    SP 条件单会额外执行一次默认分支，属控制流缺陷。
- 输入/前置条件:
  - 公开 `stra_exit_short(stdCode, qty, userTag, limitprice, stopprice)` 在带
    `limitprice/stopprice` 时登记 `COND_ACTION_SP`（`CtaMocker.cpp:1580`）；
  - 喂入可触发该条件单的 tick，进入 `proc_tick` 的 `matchedEntrust` 执行段。
- 期望:
  - 与同组 case 一致，在 `append_signal` 后 `break;`。
- 实际:
  - 缺少 `break;`，落入 `default: break;`（当前无副作用）。
- 复现步骤:
  1. `CtaMocker m(&replayer, "x", 0, false);`
  2. `m.stra_enter_long("SHFE.rb.2405", 1, "", 0, 0);` 建立持仓；
  3. `m.stra_exit_short("SHFE.rb.2405", 1, "sp", 3800.0);` 登记 SP 条件单；
  4. `m.handle_tick(...)` 喂 3800 以下的 tick 触发条件单；
  5. 代码审查确认 883-887 无 `break`。
- 严重级别: Minor（当前无可观察行为差异，属潜在控制流缺陷）
