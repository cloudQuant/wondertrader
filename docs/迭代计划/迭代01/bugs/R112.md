# R112 缺陷清单 — WtDataStorage / WtDataStorageAD（第十九波）

发现者：lane R112。所有条目均**未修改产品代码**，只记录。本轮新发现 1 条；
R52/R70/R74/R94/R100 与 R4 已登记的缺陷未重复登记。

### 复核记录（2026-10-29）

- **结论：静态源码确认的条件性产品缺陷；本轮未运行测试或独立复现。** 普通未复权 RT K 线分支没有 `_size > 0` 守卫，空块时会对非法区间执行 `lower_bound`，后续还会读取条目字段。实际 writer 代码能产生空块：首次建块初始化 `_size=0`，首条 bar 尚未写入时跨进程 reader 可看到该状态；收盘落历史成功后 writer 也会把 RT `_size` 清零。reader 的 `StdUniqueMutex` 是本地对象，不能与 writer 的 `SpinLock` 提供跨进程互斥。
- **证据边界：** 代码证明空块状态与危险表达式均存在，但本轮没有建立动态崩溃证据。实际表现是 C++ 未定义行为，可能越过映射区、读出错误切片或崩溃，不应承诺每次 SIGSEGV。现有 R132 K 线 RT 用例写入 `size=3`，不覆盖空 K 线块；R94 用例覆盖的是空历史 K 线载荷，也不是空 RT 块。
- **重复关系：** 与 BUG-R52-002/003 不重复。R112 是 `_exright != 2` 的原始 RT block 且 `_size==0`；R52-002/003 是 `_exright==2` 的 `_rt_bars` vector 右界访问和首次拷贝长度问题。R122/R132 对 R112 的引用是同一候选的交叉引用，不是新复现。

## BUG-R112-001

- 状态: 待审核
- 审查结论: 产品缺陷（静态确认；动态症状待验证）
- 严重级别: Major（空实时块进入未定义行为，可能读错或崩溃）
- 模块/文件: `src/WtDataStorage/WtRdmDtReader.cpp`
  - `readKlineSliceByRange` 当日 RT 段：L1868-1884
    （`std::lower_bound(_bars, _bars + (_size - 1), ...)` 在 L1873；回退 `pBar--/idx--` 在 L1882-1883）
  - `readKlineSliceByCount` 当日 RT 段：L2291-2307（同型 L2296/L2305-2306）
- 相关测试: 无空 RT K 线块的启用复现，本轮未运行测试。`WtDataReader::readKlineSlice`
  在 `src/WtDataStorage/WtDataReader.cpp:1808-1809` 同样先检查 `_block` 和 `_size>0`，
  Rdm 侧没有；这是实现对照，不单独证明产品接口契约。
- 输入/前置条件:
  - 当日 RT K 线块 `rt/min1/SSE/600000.dmb`（或 min5）存在，但头部 `_size == 0`。
    生产 writer 的 `getKlineBlock` 在新建块时写 `_size=0`（`WtDataWriter.cpp:1351-1410`），
    `pipeToKlines` 随后才在 writer 本地锁内增加首条 bar（`:1088-1094`、`:1122-1128`）；
    reader 的映射 helper 只检查文件和映射，不检查 `_size`（`WtRdmDtReader.cpp:2183-2215`）。
    此外收盘历史落盘成功后会清零 min1 `_size`（`WtDataWriter.cpp:2122-2124`，min5 同型
    `:2199-2201`）。因此这是可出现的跨进程短暂状态/收盘后状态；本轮未测量其生产出现频率。
  - `cInfo._exright != 2`（普通合约/股票）；
  - 调 `readKlineSliceByRange("SSE.STK.600000", KP_Minute1, 202401100900, 202401101000)`
    或 `readKlineSliceByCount("SSE.STK.600000", KP_Minute1, 5, 202401101000)`。
- 期望行为: RT 块为空时应跳过实时段（或返回空切片），不得对 `_size - 1` 求值；
  与 `WtDataReader.cpp:1809` 的 `_size>0` 守卫一致。
- 实际行为:
  1. `_size` 字段为 `uint32_t`（`src/WtDataStorage/DataDefine.h:142-147`），0 减 1 回绕；
     `begin + (_size - 1)` 因而构造不合法的搜索终点，已进入未定义行为。
  2. 随后的 `pBar` 字段读取、`pBar--`/`idx--`、范围数量计算都没有空块保护；具体读写
     地址和症状依赖映射布局及输入，静态证据不足以断言每次都越过映射边界或 SIGSEGV。
  3. `readKlineSliceByCount` 使用同一非法终点，风险根因相同。
- 影响范围: 若普通未复权读取在 writer 首条 bar 发布前或收盘清零后命中当日 RT 文件，
  range/count 都可能产生错误结果或崩溃。该候选不证明空块读取在所有部署中常见，也不涉及
  exright==2 的 `_rt_bars` vector 分支。
- 备注: 修复方向：在两处进入非复权 RT 搜索前检查 `kPair`、`_block` 和 `_size>0`；空 RT
  应跳过实时段并继续已有历史读取/补足逻辑，而非无条件提前返回 NULL。补充针对 `_size=0`
  的 range/count 用例并分别覆盖纯 RT 文件与同时有历史文件的情况；本轮未添加或运行测试。

## 本轮未重复登记的相关既有缺陷

- BUG-R52-002/003、BUG-R70-001、BUG-R100-001/002：本轮选点刻意避开其越界面。
