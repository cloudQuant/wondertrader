## BUG-R10-004（复核）WtSelEngine::on_minute_end 任务派发线程 joinable

- 状态: 待审核
- 位置: `src/WtCore/WtSelEngine.cpp:329-336`
- 证据: 命中周期任务后 `StdThreadPtr thrd(new StdThread(...))` 在循环体作用域
  结束时析构；`std::thread` 仍 joinable，析构调用 `std::terminate`。基线中
  `:265-336` 的所有 `bIgnore=false` 体均未覆盖，本轮仍不触发。
- 影响: 选股引擎任何按周期调度且真正到点的任务会终止进程。
- 用例关系: R181 只补 ticker 自动闭合与 TraderAdapter 平昨日志分支，未以该
  缺陷路径换覆盖。

## BUG-P02-003（复核）WtEngine::get_adjusting_flag 丢弃返回值

- 状态: 待审核
- 位置: `src/WtCore/WtEngine.cpp:771-777`（消费点 `WtSelEngine.cpp:146-206`）
- 证据: `if (_data_mgr) _data_mgr->get_adjusting_flag();` 后无条件 `return 0;`，

- 用例关系: 本轮未新增用例；不重复编号。

## BUG-N01-003 / BUG-P11-006（复核）getRiskParams 缺 default 时解引用 end

- 状态: 待审核
- 位置: `src/WtCore/TraderAdapter.cpp:392-402`
- 证据: 品种未命中后 `it = _risk_params_map.find("default"); return &it->second;`
  未判 `it == end()`。因此 `checkCancelLimits/checkOrderLimits` 里的
  `if (riskPara == NULL)`（`:554、:619`）是不可达分支：函数要么返回有效地址，
  要么已经 UB，不可能返回 NULL。
- 影响: 走 `initExt`（无 riskmon）或风控配置缺 default 时，读 end() 的
  `second` 是未定义行为，随后按垃圾边界值拦截下单。
- 用例关系: 本轮不构造该 UB；R181 的 TraderAdapter 用例走 `initExt` 且不调用
  风控检查。
- 备注: 与 UFT 侧 BUG-Q04-005 同构。

## BUG-R160-003（复核）WtHftRtTicker 自动闭合后 _time 写成 HHMM

- 状态: 待审核
- 位置: `src/WtCore/WtHftTicker.cpp:189`
- 证据: 自动闭合分支 `_time = thisMin;`，而 `_time` 全链路约定 HHMMSSmmm；
  下一轮 `_time/100000` 变成 0，恰好仍被 `isInTradingTime` 视为交易中。
- 影响: 自动闭合只生效一次，后续分钟依赖行情 tick；收盘强平可能延迟。
- 用例关系: R181 的 HFT 用例利用该既有行为避免 10 秒休市 sleep（与 R160
  一致），但未修改生产代码，也未据此放宽断言。
