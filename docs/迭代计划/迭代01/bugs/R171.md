## BUG-R171-001 SelMocker 未调度即结束回放会整数除零

- 状态: 已合并（主编号 BUG-R43-001；BUG-Q02-002 为关联记录）
- 分类: 已有缺陷重复观察；与 `bugs/R43.md` BUG-R43-001、`bugs/Q02.md` BUG-Q02-002 同源，
  不新增编号。
- 严重度: 若该路径执行整数除法，属于未定义行为；具体进程信号及平台表现未由本 lane 验证。
- 位置: `src/WtBtCore/SelMocker.cpp:303-307`
- 静态证据: `handle_replay_done` 的日志参数直接计算
  `_total_calc_time / _emit_times`；构造函数把 `_emit_times` 初始化为 0
  （`SelMocker.cpp:43`），只有 `on_schedule` 才会自增（`SelMocker.cpp:507`）。
  若策略从未被调度（例如空回放、只手动 `stra_set_position`、或调度前异常退出），
  结束回放即触发整数除零。
- 动态证据: `r171_btcore_residual_test.cpp` 中
  `DISABLED_R171Sel_ReplayDoneWithoutScheduleDividesByZero` 构造 `SelMocker` 后直接调用
  `handle_replay_done()`；该用例未运行，因而“启用即崩溃”不是本 lane 的动态复现结论。
- 建议: 与 `CtaMocker.cpp:665` 一致，用 `if (_emit_times > 0)` 包住平均值日志，
  或先判断再除法。

## BUG-R171-002 HisDataReplayer 把半小时线 "f" 当成小时线 "h"

- 状态: 已合并（主编号 BUG-P07-004；BUG-Q02-005 为关联记录）
- 分类: 已有映射观察；与 `bugs/P07_btcore.md` BUG-P07-004、`bugs/Q02.md` BUG-Q02-005
  重复，不新增编号。
- 严重度: 若 `"f"` 的接口契约确认为半小时，现有映射与该契约不符；本 lane 只有静态证据。
- 位置: `src/WtBtCore/HisDataReplayer.cpp:2196-2201`、`2035-2038`
- 现象: `get_kline_slice` 对 `"h"` 和 `"f"` 都执行
  `realTimes = PERIOD_TIMES_HOUR`（0xFFFFFFFF）；因此 `BarsList::_times`
  不可能是 `PERIOD_TIMES_HALF`（0xFFFFFFFE），`handle_bar_close(..., "f", ...)`
  的半小时分支（2037-2038）不可达，`"f"` 实际按小时线回放。
- 证据: 源码两处赋值相同，且此前基线 `llvm-cov show` 中 2037-2038 为 0 计数。覆盖率
  只能说明该分支在那份基线中未执行，不能替代半小时回放的行为验证；本 lane 未运行该回放。
- 建议: `"f"` 分支改为 `PERIOD_TIMES_HALF`，并补充半小时线回放用例。
- 备注: 该路径需要构造半小时会话/多周期数据才能从公开 API 稳定观测，
  本轮未加 `DISABLED_` 复现用例，仅登记静态发现。

## BUG-R171-003 SelMocker 目标价信号参数恒为 0，目标价分支不可达

- 迭代02第二轮前状态（历史）: - 状态: 待审核
- 状态: 已撤回（迭代02：NOT_BUG，原产品主张不成立）
- 分类: 公开 API 的接线/设计疑问，现有证据不足以确认是产品缺陷；不新增确认缺陷编号。
- 严重度: 未定。需要先确认产品契约是否要求公开设置目标价。
- 位置: `src/WtBtCore/SelMocker.cpp:366-369`、`591-638`
- 静态观察: `proc_tick` 只有在 `sInfo._desprice != 0` 时才使用目标价；
  但 `_desprice` 只在 `append_signal(..., price)` 中赋值，而 `append_signal`
  是私有函数，唯一调用点 `stra_set_position` 使用默认 `price=0.0`
  （`stra_set_position` 公开签名没有价格参数）。因此 `else price = _desprice`
  分支在任何公开用法下都不可达。
- 建议: 先由接口/产品契约确认目标价是否应可由公开调用方指定；若需要，提供有文档的
  参数或独立 API 并加行为测试；若不需要，删除分支或记录内部用途。当前材料不支持把它
  描述成已证实的用户功能故障。
