## BUG-R122-001

- 状态: 待审核
- 严重级别: Major（静默返回错误数据，非崩溃）
- 模块/文件: `src/WtDataStorageAD/WtDataReaderAD.cpp`
  - `readKlineSlice` 的 `array_two` 直取分支：L474-480
  - 同型写法见 `readTickSlice`：L188-194
- 测试用例: `src/TestUnits/coverage/p05_datastorage2/r122_reader_ad_branches_test.cpp`
  - `DISABLED_R122ReaderADKlineArrayTwoReturnsWrongTail`（默认不跑，`--gtest_also_run_disabled_tests` 可复现）
  - 启用对照：`R122ReaderADKlineZeroCountHitsDirectArrayTwo`（count==0 只命中分支，不触发错误数据）
- 输入/前置条件:
  - 同一 `WtDataReaderAD` 先请求 `count=3, etime=20230103093300000`，缓存 09:31/09:32/09:33，
    `boost::circular_buffer` capacity=3；
  - 再请求 `count=2, etime=20230103093500000`，LMDB 中已有 09:34/09:35，
    `update_cache_from_lmdb` 追加两条后缓冲回绕：逻辑顺序 09:33/09:34/09:35，
    `array_one()={09:33} (size=1)`、`array_two()={09:34,09:35} (size=2)`；
  - 于是 `cnt_2(2) >= count(2)` 命中 L476-480。
- 复现步骤:
  1. 在 `min1/EXQ` 播种 09:31–09:35 五条 1 分钟线；
  2. `readKlineSlice("EXQ.rb2301", KP_Minute1, 3, 20230103093300000)`；
  3. `readKlineSlice("EXQ.rb2301", KP_Minute1, 2, 20230103093500000)`；
  4. 运行 `--gtest_also_run_disabled_tests --gtest_filter=*ArrayTwoReturnsWrongTail*`。
- 期望行为: 返回最后 `count` 条，即 09:34、09:35。
- 实际行为:
  - L479 用 `&_bars[ayTwo.second - count]`（= `&_bars[0]`）作为起点；
    `circular_buffer::operator[](0)` 是逻辑首元素 09:33，而不是 `array_two` 的物理起点 09:34；
  - 正确偏移应是 `_bars[size() - count]`（本例 `&_bars[1]`），或直接用
    `array_two.first + (array_two.second - count)`；
  - 结果切片为 09:33、09:34，静默少返回最新一条并混入重复的一条。
- 影响范围: 盘中增量读取时若上次请求的 `count` 较大、本次较小，且 RT/增量数据刚好把环形缓冲写回绕，
  任意 `readKlineSlice` 调用都可能拿到错位的尾部区间；tick 侧 L191-194 同型。
- 备注: `array_two` 直取在环形缓冲**线性布局**时 `array_two.second==0`，永远走 else 分支；
  一旦回绕且 `array_two.second >= count` 就取错，故此前用例未覆盖到该分支（与报告 L477-480 零命中一致）。
  修复方向：改用 `barsList._bars.size() - count` 或 `array_two.first + (array_two.second - count)`。

## 引用（不重复登记）

- **R4-BUG-01**：`WtDataWriterAD::_async_task` 构造函数未初始化。本轮 `R122WriterADUpdateTickCacheUninitialized`
  只走 `IDataWriter` 基类 `init`（不加载缓存块），沿用 `new_writer_zeroed()` 压残值，未触发异步线程。

  (交易所,周期/合约) 第 3 次取库拿到空句柄。本轮所有 AD 读取用例每个句柄最多取 2 次，刻意避开。

  时 `_size-1` 回绕越界。本轮所有 RT K 线块都写入 ≥4 条，`readKlineSliceByCount` 只用 count=0
  且无 RT 文件，避开越界面。
- **BUG-P09-001/P09-002**：私有 `readBarsFromCacheByRange` 的 `eit--` 无首元素守卫、缺 `_bars.empty()`。
  公开路径由 `indexBarFromCache*` 守卫，本轮未从公开入口触达，保持原状。
