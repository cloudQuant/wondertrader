## BUG-R94-001

- 状态: 待审核
- 严重级别: Major（越界取址 + 计数回绕，可能崩溃或返回超长切片）
- 模块/文件: `src/WtDataStorage/WtRdmDtReader.cpp`
  - `indexBarFromCacheByRange` L1662-1671：
    `auto eit = lower_bound(...); if (eit == end) ... else { if (eit->date/time > eBar) { eit--; } eIdx = eit - begin; }`
    —— 没有 `eit == begin` 守卫；目标右界早于缓存首根时，`lower_bound` 返回 `begin`，
    条件成立后 `eit--` 退到数组之前（未定义行为），`eIdx` 随后由 `std::size_t` 回绕成 `SIZE_MAX`。
  - `indexBarFromCacheByCount` L1711-1720：同型复制，`eit--` 同样没有 begin 守卫。
  - 同型 RT 段（无 `idx == 0` 守卫）:
    - `readKlineSliceByRange` L1880-1884、L1953-1957
    - `readKlineSliceByCount`  L2303-2307、L2360-2364
- 相关测试: `src/TestUnits/coverage/q03_storage3/r94_rdm_day_backoff_test.cpp` →
  `R94RdmDayBackoffTest.DISABLED_R94RdmRangeBeforeFirstBarUnderflowsCacheCursor`
- 输入/前置条件:
  - `his/day/SSE/600010.dsb` 只有两根日线：20240105、20240110；
  - `WtRdmDtReader::init(NULL, sink)`（宿主 `calcTradingDate(0)` 返回 20240110）；
  - 调 `readKlineSliceByRange("SSE.STK.600010", KP_DAY, 202312010000, 202401011500)`，
    右界 20240101 早于缓存首根 20240105。
- 期望行为: 目标区间早于缓存首根时应返回空切片/NULL；不得对 `begin` 之前取址，
  `count` 也不能回绕（与 `readBarsFromCacheByRange` L1762-1763 已有的
  `if (eit == barsList._bars.begin()) return 0;` 保持一致）。
- 实际行为:
  1. `lower_bound` 返回 `barsList._bars.begin()`（首根 20240105）；
  2. `eit->date > eBar.date` 成立，执行 `eit--`，指针落到数组前一个元素（UB）；
  3. `eIdx = eit - begin = SIZE_MAX`，随后 `curCnt = eIdx - sIdx + 1` 回绕；
     `readKlineSliceByRange`/`ByCount` 用这个计数调用 `WTSKlineSlice::create`，
     典型结果是超大切片、越界读或崩溃。
  - ByCount 的 RT 分支更直接：`rtCnt = min((uint32_t)idx + 1, count)` 在 `idx == SIZE_MAX`
    时把 `0xFFFFFFFF` 当条数，`sIdx = idx + 1 - rtCnt` 再产生越界起点。
- 复现步骤:
  1. 在 `q03::Sandbox` 下写上述两根日线；
    2. `WtRdmDtReader reader; reader.init(NULL, &sink);`
  3. 调用用例中的 `readKlineSliceByRange`（或 `readKlineSliceByCount(..., 1, 202401011500)`）；
  4. 用例已标记 `DISABLED_`，`--gtest_also_run_disabled_tests` 可复现（预期 SIGSEGV/断言失败）。
- 影响范围: 任何「查询窗口右界早于该合约缓存首根」的调用：回放预热、区间参数写错、
  新上市合约按更长历史窗口读取、跨品种批量读取时未对齐首日等。日线/分钟线两套
  `isDay` 分支都受影响；RT 分支还额外影响 `readKlineSliceByCount`。
- 备注: 修复方向与 BUG-R70-001 相同：在 `eit->date/time > eBar` 的回退前补
  `if (eit == barsList._bars.begin()) { count = 0; return NULL; }`（ByRange 返回 NULL，
  ByCount 返回空）；RT 段补 `if (idx == 0) break/返回空`。建议与 R70-001、R52-002、
  R52-003 一并评审，统一所有 lower_bound 回退的边界语义。
