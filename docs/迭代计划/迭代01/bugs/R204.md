## 新增缺陷

### BUG-R204-001 WtUftCore/TraderAdapter::isTradeEnabled 声明 inline 但无 TU 可见定义

- 位置: `src/WtUftCore/TraderAdapter.h:192`（`inline bool isTradeEnabled(...) const;`）、
  `src/WtUftCore/TraderAdapter.cpp:1908-1917`（唯一非 inline 定义）
- 现象: 头文件把成员声明为 `inline`，定义只存在于 .cpp；编译器因此不在
  `TraderAdapter.cpp.o` 中产出该函数的外部符号（`nm -C` 无匹配）。任何其他
  翻译单元调用都会触发 `-Wundefined-inline`，且链接期无符号可用。
- 影响: 公开的风控交易开关无法被外部模块/测试调用；`TraderAdapter.cpp:1908-1917`
  的 10 行在进程外不可覆盖。既有 q04/q01/n03 用例均以注释回避（同类记录
  BUG-Q04-006/BUG-N01-004/BUG-N03-006）。
- 建议: 去掉头文件 `inline`，或把定义移入头文件。
- 状态: 待审核

## 既有缺陷复核（仍成立）

### BUG-R194-001 WtUftEngine 切片入口 return NULL 后的整段实现不可达

- 位置: `src/WtUftCore/WtUftEngine.cpp:179-243`，以及依赖 bar 订阅表的
  `on_bar` 循环 `:592-602`
- 现象: `get_tick_slice`/`get_kline_slice` 首行 `return NULL`，后续 `_data_mgr`
  取数与 `_bar_sub_map` 写入全部为死代码；`_bar_sub_map` 无其他公开写入点，
  `on_bar` 永远空循环。
- 影响: UFT 策略通过 `stra_get_bars`/`stra_get_ticks` 恒拿不到历史切片；本 lane
  的 `R204UftContext.SliceStubsReturnNullThroughContext` 锁定该桩行为。
- 状态: 待审核

### BUG-R11-002 数值 watch_param 在 ShareManager 缺失时解引用空指针

- 位置: `src/WtUftCore/UftStraContext.cpp:705-727`
- 现象: 5 个数值 `watch_param` 重载直接 `*ShareManager::self().allocate_value(...)`；
  未建共享内存段时 `allocate_value` 返回 nullptr，调用即段错误。
- 影响: 无 shm 的单元测试/独立回放不能触碰这些公开接口；本 lane 保持不驱动。
- 状态: 待审核

### BUG-Q04-004 流量风控频率窗口分支无写入点

- 位置: `src/WtUftCore/TraderAdapter.cpp:337-340、391-392、419-420`（写入点注释）、
  `:1878-1903、1940-1965`（读取分支）
- 现象: `_order_time_cache`/`_cancel_time_cache` 仅有的写入语句全部被注释，
  `checkCancelLimits`/`checkOrderLimits` 的频率窗口分支永远不执行，只剩总量限额生效。
- 影响: 风控“N 秒内 M 次”配置实际失效；本 lane 未重复登记新编号。
- 状态: 待审核
