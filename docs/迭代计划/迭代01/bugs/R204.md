## 本轮记录（含重复项）

### BUG-R204-001 WtUftCore/TraderAdapter::isTradeEnabled 声明 inline 但无 TU 可见定义（重复记录）

- 位置: `src/WtUftCore/TraderAdapter.h:192`（`inline bool isTradeEnabled(...) const;`）、
  `src/WtUftCore/TraderAdapter.cpp:1908-1917`（唯一非 inline 定义）
- 现象: 头文件把成员声明为 `inline`，定义只存在于 .cpp；调用方 TU 看不到函数体，
  Clang 可报告 `-Wundefined-inline`，而本目标对象文件 `nm -C` 无匹配符号。链接结果
  取决于实际编译/链接构成；不能从静态符号缺失推出任意调用必然运行时崩溃。
- 影响: 公开的风控交易开关跨 TU 编译/链接可用性受影响。本条与
  `BUG-N03-006`/`BUG-Q04-006` 是同一位置和根因的重复登记，不重复计数；本 lane
  没有 active 测试直接调用该函数。
- 建议: 去掉头文件 `inline`，或把定义移入头文件。
- 状态: 已合并（主编号 BUG-N03-006；BUG-Q04-006 为关联记录）

## 既有条目复核

### BUG-R194-001 WtUftEngine 切片入口当前为文档化未实现 stub（非产品缺陷）

- 位置: `src/WtUftCore/WtUftEngine.cpp:179-243`，以及依赖 bar 订阅表的
  `on_bar` 循环 `:592-602`
- 复核: `src/Includes/IUftStraCtx.h` 的 `stra_get_bars`/`stra_get_ticks` 文档明确写
  “暂未实现”；`WtUftEngine.cpp:179-182,209-212` 直接返回 `NULL`，后续取数和订阅代码
  不可达。因此当前行为与已声明契约一致，不能作为已违反契约的产品缺陷。
- 影响/测试: `R204UftContext.SliceStubsReturnNullThroughContext` 断言 NULL，属于 stub
  行为测试；不能据此报告 UFT 历史切片功能失效。若后续决定支持切片，再实现读取与订阅
  行为，并补对应 API 回归。
- 状态: 已撤回（接口契约明确说明历史切片当前为未实现 stub，不构成产品功能缺陷）

### BUG-R11-002 数值 watch_param 在 ShareManager 缺失时解引用空指针

- 位置: `src/WtUftCore/UftStraContext.cpp:705-727`
- 现象: 5 个数值 `watch_param` 重载直接 `*ShareManager::self().allocate_value(...)`；
  未建共享内存段时 `allocate_value` 返回 nullptr，调用即段错误。
- 影响: 无 shm 的单元测试/独立回放不能触碰这些公开接口；本 lane 保持不驱动。
- 修复方向: `allocate_value` 返回 NULL 时避免解引用并明确报告失败；返回对应 `initVal` 与基类默认实现一致，是候选方案，不能据此声称监听已经成功。为五个数值重载分别覆盖未初始化状态和成功监听路径。
- 状态: 已合并（主编号 BUG-R11-002）

### BUG-Q04-004 流量风控频率窗口分支无写入点

- 位置: `src/WtUftCore/TraderAdapter.cpp:337-340、391-392、419-420`（写入点注释）、
  `:1878-1903、1940-1965`（读取分支）
- 现象: `_order_time_cache`/`_cancel_time_cache` 的时间戳写入点被注释，检查方法
  读取的时间窗没有由该模块写入的数据。此外，`TraderAdapter.cpp:364,444,724,
  996,1025,1054,1083` 的 `checkCancelLimits`/`checkOrderLimits` 调用也都被注释；
  因而正常下单/撤单提交路径没有自动接入这些检查。不能据此表述为“仅总量限额生效”。
- 影响: 静态可确认的是时间窗口路径没有当前写入数据，且提交路径上的检查门控未接通；
  本 lane 无 public 订单链集成测试，不能声称已经动态验证风险损失或生产合规后果。
- 修复方向: 若产品契约仍要求自动限额，在正常订单/撤单入口恢复检查调用，并按一致
  合约 key 记录时间戳；用受控输入覆盖总量限额、窗口内超限和窗口过期。现有直接调用
  `check*Limits` 的单测只覆盖方法本身，不证明正常订单链接线。
- 状态: 已合并（主编号 BUG-Q04-004）
