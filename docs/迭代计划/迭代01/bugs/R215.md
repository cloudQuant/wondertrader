## BUG-R215-001 WtDataReaderAD 第三次 get_k_db 命中被掏空的 shared_ptr，刷新路径空指针崩溃

- 状态: 待审核
- 严重度: Blocker（公开读 API 段错误；RT 缓存刷新分支事实不可达）
- 位置:
  - `src/WtDataStorageAD/WtDataReaderAD.cpp:576-578`（`get_k_db` 命中时 `return std::move(it->second)`）
  - `src/WtDataStorageAD/WtDataReaderAD.cpp:272-274`（`update_cache_from_lmdb` 直接 `WtLMDBQuery query(*db)`，未判空）
  - 调用点 `:444-456`（RT bar 晚于 etime 的二次回源）、`:287-290`（同时间戳覆盖）
- 现象: `cacheBarsFromStorage` 首取 `get_k_db` 后槽位仍有效；首读的
  `update_cache_from_lmdb` 是第 2 次取，`std::move` 把 map 槽位掏空但返回值可用；
  下一次刷新是第 3 次取，得到空 `WtLMDBPtr`，`WtLMDBQuery(*db)` 在
  `WtLMDB::is_readonly()` 读 `this+0x10`，`EXC_BAD_ACCESS`（SIGSEGV）。
- 证据: 崩溃报告触发栈
  `WtLMDB::is_readonly -> WtLMDBQuery::WtLMDBQuery -> WtDataReaderAD::update_cache_from_lmdb
  -> WtDataReaderAD::readKlineSlice -> R203AdResidualTest...TestBody`（rc=139）。
- 影响: 同一 reader 对同一 (交易所, 周期) 的第三次取库起随时空指针；本轮原
  `R203ReaderRtCacheAheadOfEtime...` 即在此崩溃。
- 测试处理: 原输入、原断言完整保留在 `DISABLED_R203ReaderRtCacheAheadOfEtimeDoesNotAppendFutureBar`；
  另增启用用例 `R203ReaderRtCacheBranchesWithIsolatedReaders`，每次刷新换新 reader，
  只驱动 450-456/459-461 分支。
- 修复建议: `get_k_db/get_t_db` 返回 `it->second`（拷贝）而非 `std::move`；
  `update_cache_from_lmdb` 对 `db == NULL` 判空返回。
- 交叉引用: `bugs/R144.md` BUG-R144-002、`bugs/R185.md` 观察 1、
  `bugs/p05_datastorage2.md` BUG-P05-001、`bugs/R4_adstorage.md` R4-BUG-02、
  `bugs/R21_adstorage.md` R21-BUG-05。

## BUG-R215-002 WtRdmDtReaderAD 首次载入把末笔覆写回首笔，跨日区间丢首日

- 状态: 待审核
- 严重度: Blocker（静默数据损坏，跨日区间少返回记录）
- 位置: `src/WtDataStorageAD/WtRdmDtReaderAD.cpp:135-144`，重点 `:140`
  （`WTSTickStruct& curTs = tickList._ticks.front(); ... curTs = tickList._ticks.back();`）
- 现象: `curTs` 是指向 `_ticks[0]` 的引用，赋末笔不是重新绑定，而是把末笔整体
  `memcpy` 回首笔。三笔跨 20240109/20240110 的 tick 载入后首元素被替换成末笔，
  起点 20240109 10:00 的第二次 `lower_bound` 结果错位，区间只返回 2 笔。
- 证据: `R203AdResidualTest.R203RdmCrossDateTickRangeKeepsAllTicks`：
  `tick_count(slice)` 实际 2、期望 3，`at(0)->action_date` 实际 20240110、期望 20240109。
- 影响: 所有「读区间再取子窗」的调用方拿到错位 tick；
  `WtRdmDtReaderAD.cpp:238-243` 的日期比较分支不可达。
- 测试处理: 原输入、原断言保留，改为
  `DISABLED_R203RdmCrossDateTickRangeKeepsAllTicks`。
- 修复建议: `:140` 改为 `const WTSTickStruct& curTs = tickList._ticks.back();`，保持载入顺序。
- 交叉引用: `bugs/R32_adstorage.md` BUG-R32-001、`bugs/R185.md` 观察 2。

  `DISABLED_PublicTradeSwitchNeedsExternallyVisibleDefinition`；启用的
  `PublicStateAfterInitExt` 只断言 `initExt` 后的 `state()`。
- 修复建议: 去掉头文件声明的 `inline`，或把定义移入头文件。
- 交叉引用: `bugs/R202.md` BUG-R202-003、`bugs/q04_uftcore3.md` BUG-Q04-006、

## BUG-R215-004 readKlineSlice 在追加 RT bar 前夹紧 count，追加结果被截断

- 状态: 待审核
- 严重度: Major（公开读 API 少返回 K 线；RT 缓存追加对返回条数无效）
- 位置: `src/WtDataStorageAD/WtDataReaderAD.cpp:423`（缓存检查前
  `count = min(barsList._bars.size(), count)`）、`:473`（追加后的第二次夹紧）
- 现象: 请求 `count=10`、LMDB 只有 1 根、RT 缓存再追加 1 根时，`:423` 已把 `count`
  夹到 1，`:473` 再算 `min(2, 1)`，最终只返回 1 根；追加的 RT bar 被丢弃。
  `R203ReaderRtCacheAhead...` 的 09:40 读期望 2 根，换新 reader 后实测仍 1 根。
- 影响: `readKlineSlice` 在“存储根数 < 请求条数且 RT 缓存有更新”时少返回数据，
  且 `_last_from_cache` 语义与条数不一致。
- 测试处理: 启用分支用例改用 `count=1` 只验证追加分支
  （返回 1 根 09:36 是 count=1 的正确结果）；原 `count=10` 的两根断言保留在
  `DISABLED_R203ReaderRtCacheAheadOfEtimeDoesNotAppendFutureBar`。
- 修复建议: 把 `:423` 的 count 修正移到 RT 缓存追加之后，或追加后按原始请求条数重算。
- 交叉引用: `bugs/R144.md` BUG-R144-002（同一函数刷新路径）。

## BUG-R215-005 get_order_queue_slice 在 lower_bound 返回 end 时多报一条幽灵记录

- 状态: 待审核
- 严重度: Major（回调 count 大于实际记录数，可能越界读）
- 位置: `src/WtBtCore/HisDataReplayer.cpp:2619-2631`
  （`_cursor = idx + 1`；`eIdx = _cursor - 1`；`realCnt = eIdx - sIdx + 1`）
- 现象: 只有 1 条 09:00 记录、`_cur_time=09:30` 时，`lower_bound` 返回 `end()`
  （idx=size=1），`_cursor=2`，`eIdx=1`，`realCnt=2`，但 `_items.size()==1`；
  `WTSOrdQueSlice::create(..., data()+0, 2)` 向回调报告 2 条。
- 证据: `R205BtPorterLevel2.HftLevel2GettersServeStoredBlocksAndRejectMissing`
  原配置 `stime=0930` 时 `hft_get_ordque/orddtl/trans` 均返回 2、回调 count=2；
  把回放起始时间调到 09:00（游标正好落在首条）后返回 1。
- 影响: Level2 getter 多报记录并让回调按越界 count 读取；order detail/transaction
  getter 中同型 `_cursor = idx + 1` 写法也可能受影响。
- 测试处理: 该用例 `stime` 改为 `202001020900`，输入与期望（1 条）保持一致；
  不改产品代码。
- 修复建议: `lower_bound` 返回 `end()` 时把 `_cursor` 夹到 `_items.size()`，
  或把 `realCnt` 夹到 `_items.size() - sIdx`。
- 交叉引用: `bugs/R103.md`（同型 `_cursor = size+1` 越界）、
  `bugs/p04_btcore_replayer.md` BUG-P04-010、`bugs/R210.md` 游标边界观察。
