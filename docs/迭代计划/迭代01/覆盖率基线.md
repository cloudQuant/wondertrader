## 复现命令

```bash
rm -rf /tmp/wt_cov && cmake -S src -B /tmp/wt_cov -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug -DCMAKE_POLICY_VERSION_MINIMUM=3.5 \
  -DWT_ENABLE_COVERAGE=ON
cmake --build /tmp/wt_cov -j 8
mkdir -p /tmp/wt_cov_run && cd /tmp/wt_cov_run
LLVM_PROFILE_FILE=/tmp/wt_cov_run/test.profraw \
  /tmp/wt_cov/build_x64/Debug/bin/TestUnits/TestUnits < /dev/null
xcrun llvm-profdata merge -sparse test.profraw -o test.profdata
xcrun llvm-cov report /tmp/wt_cov/build_x64/Debug/bin/TestUnits/TestUnits \
  -instr-profile=test.profdata
```

> 注意：上表是“仅链接进 TestUnits 的代码”的报告；项目全量对象报告需要把各模块 `.o` 通过 `-object` 传入，详见 `tools/coverage_report.py`。
