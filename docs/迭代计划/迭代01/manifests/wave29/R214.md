## 2. 本轮关键测量发现（头文件内联行的 0 覆盖是口径问题）

`WtRtRunner.h` 18 行、`WtBtRunner.h` 36 行长期显示 0，但对应调用早已 PASS：
R35/q06 的 `registerExtDataLoader`、R143/R173 的四个事件回调与访问器均 PASS。
本轮确认 R213 的最小实验结论同样适用于这两个头：测试目标的
`-isystem <repo>/src` 使经该路径命中的头文件被 clang 当作系统头，
**不生成覆盖映射**；统计里的 0 行来自未插桩副本。

修正方式（不改产品代码）：把
`#include "../../../WtPorter/WtRtRunner.h"` /
`#include "../../../WtBtPorter/WtBtRunner.h"` 放在测试文件所有 include 之前，
令其按用户头编译；后续经 `-isystem` 的同名包含被 `#pragma once` 挡掉。
`r214_porter_runner_api_test.cpp` 与 `r214_btporter_runner_inline_test.cpp`
即为此目的新增，覆盖 18 + 36 行。

## 4. 夹具与安全性

- WtPorter：进程单例 `reset_singleton()`（析构 + placement new）隔离；HFT 配置用
  临时目录内 sessions/commodities/contracts，`createHftContext` 绑定不存在的 trader
  （只走 map 查询）；不加载策略插件、不接柜台、不起行情线程。
- WtBtPorter：Level2 块由 WtDtHelper 公开导出写系统临时目录，`mode=bin` 只读该目录；
  `prepare_inst_dir()` 在构建目录里定位 `libWtDataStorage`；异步用例只跑 `mode=none`
  空回放，`stop_backtest()` join worker。
- TraderMocker：沿用 `r113_mocker_common.h`（临时 cwd、最小 BdMgr、ITraderSpi 快照、
  本机回环 UDP）；每条用例 `release()` 在 TearDown join；`disconnect` 用例刻意不
  `connect()`，避免留下未停止的 io worker。
- 未使用 `#define private public`、未镜像私有布局；无真实柜台/行情、无共享内存、
  无长睡眠（最长 120ms）；临时文件均按 pid+tag 隔离并在用例末尾清理。
