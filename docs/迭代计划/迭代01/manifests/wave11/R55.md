## 4. 留白面及原因

| 未覆盖面 | 原因 |
|---|---|
| `CodeHelper::find` 反向查找无 `.` 输入、`stdCodeToStdHotCode("ABC")` 等 | BUG-L01-001：无符号下标回绕，触发即越界读；不在本 lane 重制崩溃 |
| `rawFutOptCodeToStdCode` 全数字/前 3 字符无数字 | BUG-L01-014：`size_t` 回绕/`idx-3` 越界，无法安全构造 |
| `extractStdChnFutOptCode` 品种段无数字、`extractStdCode` 无 `.`/第三段为空 | BUG-L01-012 / BUG-L01-013：`mpos=-1`、`npos` 长度拷贝、`ext[-1]`，触发即崩溃 |
| `EncodingHelper::isGBK` 的失败分支 | BUG-L01-005：不推进下标会死循环；只覆盖合法双字节与纯 ASCII |
| `EncodingHelper::isUtf8` 截断多字节序列 | BUG-R55-003：越界读 `data[len]`，不能作为确定性启用用例；已在缺陷文件登记 |
| `UTF8toChar/ChartoUTF8` 的 iconv 失败分支 | `iconv_open` 在本机对 utf-8/gb2312 恒成功，没有稳定注入口；失败时输出语义也无契约 |
| `TimeUtils` 的 `_MSC_VER`/Windows 分支、`getTZOffset` 的夏令时细节、真实挂钟精确值 | 平台不可达或硬规则禁止用当前时间做期望；本 lane 只做结构断言 |
| `TimeUtils::fasttime` 负 epoch、`getWeekDay` 非法日期 | BUG-R16-01 / BUG-L01-018：前者算错、后者可能空指针解引用 |
| `StrUtil::replace` 空 src、`standardisePath("")` | BUG-R16-03 死循环 / BUG-R16-04 越界读 |
| `IniHelper` 长键 63 字符截断、`save` 空文件名/写失败、`load` 失败仍置 loaded | 已由 BUG-R16-05/06/17 记录，主路径已覆盖，不重复制造文件系统错误 |
| `BoostFile` 的 `_WIN32 ReadFile` 分支、`read_file_contents` 的 const 缓冲写入 | 平台不可达 / BUG-R16-15 的 UB 面，不写入断言 |
| `WtKVCache::resize` 的三类 logger 失败分支、`put` 超 64 字节 | 需要精确让已存在可写文件的扩尾/mmap 失败；超长写为 BUG-R16-07，已有 DISABLED 证据 |
| `StdUtils::read_file_content` 的 `gcount != length` 分支 | 需要“打开后文件变短”的进程内竞态，无法稳定构造 |
| `BoostMappingFile` 构造 `mapped_region` 抛异常时的 `_file_map` 清理 | `new` 抛异常路径无稳定注入点；只覆盖返回 null/正常路径 |
| `ModuleHelper.hpp` 的 Windows `DllMain`/`g_dllModule` 分支 | 平台不可达；`getBinDir` 已被 r16_logger_dll 用例覆盖，本 lane 不重复 |
| `Converter.hpp` 的 `from_str(std::string&)` | BUG-L01-011：libc++ 下该重载无法实例化；数值解析主路径已由 L01 覆盖 |
