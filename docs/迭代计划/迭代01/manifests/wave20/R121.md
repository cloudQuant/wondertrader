## 6. 留白面及原因

1. ExecMocker `_exec_unit` 非空整族（136、140-192、270-335）：R111 的
   `InitWithRealExecuterAndInitSchedule`/`ScheduleNegativeAndPositiveVolumeModes`
   在 `_exec_unit->init` 后崩溃（日志停在 `[ RUN ]`），本轮不重试。
2. Cta `handle_schedule`/`step_calc`/hook 等待（1060-1200）：线程/墙钟接缝，
   按约束不进入；`add_chart_mark/set_index_value`（2157-2227）仅在
   `_is_in_schedule=true` 的策略回调内可调，DualThrust 不调用。
3. Cta `do_set_position` 的同量/空品种守卫（1613-1618）：`stra_set_position`
   在进入前已做同值与品种校验，`do_set_position`/`append_signal` 均为 private，
   公开 API 不可达；`dump_stradata`/`dump_chartdata` 的目录创建（215、317）
   因 `dump_outputs` 先 `create_directories`，在 `handle_replay_done` 内恒不执行（死行）。
4. Sel 的 `_desprice!=0`（368-369）、同量/空品种（656/660）、空明细查询
   （1023/1049）：公开 `stra_set_position` 只能产生 `_desprice=0` 且提前校验；
   `append_signal`/`do_set_position` 为 private，公开面不可达。
5. Hft `_ticks` 缓存（888-893）只 create/release 从不写入；与 R92/R111 结论一致。
6. Uft 会话回调（361/366）与 `stra_enum_position`（1041-1042）对 `_strategy`
   无判空，已有 BUG-R72-001/P08 族登记；本轮绕开。
7. HisDataReplayer 的 bin/loader 数据分支（3300-4360）需要 dsb fixture，
   不在本轮公开小面内；R103/R111 已覆盖的任务日历、notifier、复权后缀未重复。
