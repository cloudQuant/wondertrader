## 5. 留白面及原因

1. **EventNotifier 的 JSON/MQ 转发（约 119 行）**：只有 `_mq_sid != 0` 才进入 asio 任务；
   `init` 成功要真实 `dlopen WtMsgQue` + `create_server`，并起 2ms 轮询线程，属本轮禁止的
   真实 MQ/长线程接缝。`tradeToJson/orderToJson` 还是 private，只能由该 lambda 调用。
2. **ShareManager 已初始化后的真实共享域（init_domain 与 helper 成功路径）**：
   `init_master` 会在 CWD 建 `.share/.sync` 映射文件，属真实共享域；本轮只补“已装载但未建域”
   的 wrapper 转发，不建共享内存。
3. **TraderAdapter 频率风控（1864、1878-1902、1926、1940-1965）**：时间缓存写入语句在
   产品里被注释（死代码）；`getRiskParams` 缺 default 时对 `end()` 取址，`riskPara` 恒非空，
   1864/1926 不可达；`isTradeEnabled` 只有 inline 声明，外部 TU 不可链接。
4. **UftStraContext 数值 `watch_param`（705-727）**：`allocate_value` 返回 nullptr 被直接解引用
   （沿用 BUG-R11-002），启用即崩；`stra_get_bars/ticks/order_detail/order_queue/transaction`
   的 `sub_*` 行（944-982）需要引擎返回非空切片，UFT 侧无数据注入点。
   `load_local_data` 的 map 失败 else 分支（1209-1213、1257-1261、1305-1309、1353-1357）
   需要 BoostMappingFile 抛异常，公开 API 无法确定性构造。
5. **WtUftTicker 215-221（跨零点）、230-235（收盘 on_session_end）**：自动闭合用例使用
   0-2400 全天时段，闭合后仍在交易时段才能立即 stop/join；若把收盘时间设成闭合分钟，
   线程会落进 10s 休息分支，join 等待不可接受。两段行号保留为时间轴接缝。
6. **WtUftEngine 592-602（on_bar 分发）**：`_bar_sub_map` 只由 `get_kline_slice` 写入，
   而后者首行 return NULL（BUG-R123-001），公开 API 无法登记 K 线订阅。
7. **ParserAdapter 90-93 / 153-156 / 192-195**：构建产物里没有“导出 createParser 但返回 NULL”
   或“init 返回 false”的插件；现有 ParserCTP/Femas/UDP/Shm 的 init 均返回 true，不伪造插件。
8. **UftStrategyMgr 82-86**：需要 `createStrategyFact` 返回 NULL 的插件；产品工厂恒返回对象。
9. **ActionPolicyMgr 154-158**：config 的 filters 一定指向同一 cfg 内已创建的规则组，
   `_comm_rule_map` 不会映射到不存在的组名；默认组缺失会 assert/UB（既有排除）。
10. **WtUftDtMgr 48-52、89-100**：`_bars_cache/_ticks_cache` 在 `.cpp` 内从未赋值，
    相关释放与历史 tick 追加分支不可达（BUG-R123-002）。
11. **WtDtServo/WtDataManager 64-85**：模块装载失败/符号缺失后仍执行 `_reader->init`，
    启用即空指针崩溃（既有 BUG-Q05-001/R8-002 一族）；`145-156` 的
    `get_session_info(sid,false)` 是 private 且所有调用点传 true；`184` 需要
    `extractKlineData` 对非空 tick 返回 NULL，不可构造。
12. **WtDtServo/ParserAdapter 129-138、192-200**：同 7，无可驱动插件。
13. **头文件 inline 行（WtUftCore 42 行、WtDtServo 6 行）**：均为公开内联访问器，由上述
    用例间接执行；不再单列。
