## 4. 解释器/运行时注意（交主控评审）

- **loader tick 表末尾故意多放一笔 15:01**：`getNextTickTime` 的游标差一
  （p07 BUG-P07-001/005）会把最后一笔当「没有下一笔」；若 15:00 是最后一笔，
  `replayHftDatas` 会因 tick 耗尽返回 false，`_tick_simulated` 重新变 true。
  多放一笔后 15:00 是可看到的下一笔，`nextTime/100000 >= etime` 正常 break，
  成功臂才稳定。
- **SelMocker 不调用 `handle_replay_done`**：`_emit_times==0` 时整数除零
  （BUG-R43-001）。分钟/滑点用例只断言切片、持仓与资金，不落盘。
- **UftMocker 不调用 `session_begin/end` 与 `stra_enum_position`**：无策略时
  无条件解引用 `_strategy`，见 BUG-R72-001 与 p08 同族记录。
- **Hft/Uft 成交手数拆分使用 `splitVolume`**：内部 `srand(time(NULL))`，
  单笔成交可能被拆成 1~N 笔，但总手数/持仓/费用确定。断言只取总量与
  「至少 N 行日志」，不断言拆分笔数。
- 所有用例不启动线程、不等待墙钟、不访问网络/柜台；`run()` 是同步循环，
  bar 数最多 5 天、tick 最多 4 笔/天。
