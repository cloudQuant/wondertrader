## 1. 为什么补这些面

先用当前全量 profdata 的 `llvm-cov show` 对三文件逐行取「count==0」清单，再与 R52/R70/R23/R1 的
manifest/留白表去重。真正的剩余块集中在：

1. `WtRdmDtReader::init(cfg!=NULL)` + `loadStkAdjFactorsFromFile` + 股票复权因子回放：R23/R52/R70
   都因「init 会起 5 秒巡检线程」整块留白；本轮只放一条用例（析构 join 最多 5 秒），其余仍
   `init(NULL)`。
2. `WtRdmDtReader` 逐笔历史（queue/detail/trans）的 **正常装配** 与短文件/尺寸守卫：R70 的
   `R70RdmHisHftFilesBuildAndReject` 在运行日志里停在 `[ RUN ]` 没有结束（疑似挂死/崩溃），
   因此这些分支在全量 profdata 里仍为 0；本轮用不同交易日避开「queue 缓存污染 dtl/trans」的
   已知缺陷（R1_wtdatastorage #2 / BUG-R74-001），把正常面补齐。
3. `WtRdmDtReader` 的 tick 区间 RT 边界（eIdx==0、pTick--、endTDate>curTDate 收盘右界）与
   HOT 候选 tick/切段短文件守卫。
4. `WtDataReader` 的 `his_path` 数组、逐笔历史正常装配（etime==0 的 sink 时钟）、HOT 原始代码、
   K 线 RT 右界回退与 `onMinuteEnd` 的非复权回调/时间未到 break。
5. `WtDataWriter` 的 `minbar_price_mode==1` **合并 bar** 分支、NULL dumper、无 tick 收盘、
   cache.dmb 重启读回一致性。

## 3. 留白面及原因

1. **`WtRdmDtReader` 5 秒巡检线程的淘汰体**（:87-166 中 `tPair._block = NULL` 的 6 个分支）：
   `_last_time` 由 `getRT*Block` 写成当前墙钟，淘汰条件要求 `now > _last_time + 300000`，
   公开 API 无法把 `_last_time` 拨回 5 分钟前；若显式等 5 秒只能覆盖循环外壳，析构还要再等
   一轮 5 秒，收益/耗时比过低。本轮只用一条用例覆盖 init/线程启动与析构 join，淘汰体留白。
2. **`getRT*Block` 的 `_last_cap != _block->_capacity` 重映射**（Rdm :2027-2036 / :2067-2076 /
   :2107-2116 / :2147-2156 / :2204-2213，Reader :2192-2205）：R52 曾用「读一次→改文件头 capacity
   →再读」尝试，测试通过但日志没有 `expanded to`，说明只读映射未观察到外部改写；要可靠触发
   需要 writer 在同一进程内扩块并让 reader 重映射，超出本 lane 的公开 API 接缝，未硬闯。
3. **`WtRdmDtReader/WtDataReader` 的 exright==2 实时 `_rt_bars` 分支**（Rdm :1909-1981 /
   :2316-2372）：受 BUG-R52-002/003（首次 memcpy 多一条、尾部 idx==size 越界）阻断，R52 已
   登记 `DISABLED_`，本轮不重复。
4. **`WtDataReader::cacheIntegratedBars` 的 HOT 包裹文件读取**（:1019-1041）：BUG-R52-001 变量
   遮蔽导致必抛异常，R52 已固化，未重复。
5. **`WtDataWriter` `CMD_CLEAR_CACHE` 分支** :2240-2391（含 300s 重试 sleep）：任务令禁止。
6. **`WtDataWriter::check_loop`** :1616-1696：10s 节拍 + 600s 过期判定，依赖墙钟且线程不可 join。
7. **`resizeRTBlock` 异常/重映射失败** :336-357、`get*Block` 的 "Mapping file failed" :710-714 /
   :804-808 / :899-903 / :1002-1006 / :1387-1392、`dump_bars_to_file` 的 create_or_open 失败
   :2126-2129 / :2203-2206：需要可控磁盘写失败/映射失败，公开 API 下无法稳定只命中该 else。
8. **`WtDataWriter::proc_block_data` :1849-1854**、`WtDataReader::proc_block_data` :81-86：
   `!bCmped && !bOldVer` 已在函数开头 return，属死代码。
9. **`WtRdmDtReader::readBarsFromCacheByRange`**（:1729-1787）：私有且当前无调用者，公开 API
   不可达，未覆盖。
