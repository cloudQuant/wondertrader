## 2. 夹具修复细节（第 1、2 条）

- 读端真实路径（`WtRdmDtReader.cpp:705/880/1054`）：
  `_base_dir + "his/{queue|orders|trans}/" + exchg + "/" + endTDate + "/" + code + ".dsb"`。
- 读端真实路径（`WtDataReader.cpp:546/703/860`）：
  `{his_dir}{queue|orders|trans}/{exchg}/{endTDate}/{code}.dsb`。
- 原夹具两处都写成 `his/<kind>/20240109/600000.dsb`，`StdFile::exists` 不命中 → 直接返回 NULL。
  已改为 `his/<kind>/SSE/20240109/600000.dsb`。
- 补上路径后暴露第二个夹具假设：`WtRdmDtReader` 与 `WtDataReader` 的 queue/orders/trans
  三个历史入口都用 `_his_ordque_map` 做装载判断（**BUG-R74-001 / R100-001**，既有）。
  同一 reader 先读 queue 后，orders/trans 会跳过装载、返回空块。
  用例目标是比较器的跨日/同日两臂，不是历史缓存复用，故改为**每个入口新建一个 reader**
  （Rdm 用 `init(NULL, &_sink)`；Reader 用同一 cfg 重新 init），断言逐条不变。
- 未改任何期望值；que/dtls/trans 的条数、首条日期、末条时间/序号断言全部保留。
