## 3. 夹具与安全性

- `r180_common.h`：只读复用 `p03/r161_common.h`（csv 回放夹具、NullSink、tick 构造）
  与 `p03/r72_common.h`（Loader、临时目录、bar 构造）；新增
  `make_exec_cfg`（真实插件 + TWap 参数，`total_times=4` 避免除零）、
  `make_m5_bars`、`make_daily_bars`、`line_count`。
- 所有临时文件只落系统临时目录（`r72_*_<pid>`），TearDown `remove_all`；
  不联网、不启线程、不读挂钟（TWap 的 `on_tick` 仅在未 `handle_init` 时到达，
  `_channel_ready=false` 会在 `do_calc` 的墙钟比较之前返回）。
- 仅走公开 API：`ExecMocker::init/handle_init/handle_tick/handle_schedule/
  handle_entrust/handle_order/handle_trade/buy/sell/cancel/getPosition/getUndoneQty/
  handle_replay_done`；`HisDataReplayer::init/prepare/run/get_kline_slice`；
  `HftMocker::stra_buy/stra_cancel/stra_get_undone/handle_tick`。
  无 `#define private public`、无类布局镜像、无宏改写。
- 用例 2/3/4 刻意不调用 `handle_init`：TWap 的 `do_calc` 在发单臂尾部
  `curTick->release()` 但不清空 `_last_tick`（BUG-R180-001），保持
  `_channel_ready=false` 可让 `do_calc` 在释放前返回，避免第二个 tick 的 UAF。
  用例 1 的 `handle_init` 时 `_last_tick` 为空，同样在释放前返回。
- 语法门禁：新增 `.cpp.tmp` 经 `gate_flags/CoverageTests_btcore.sh` 编译通过
  （0 error），随后改名为 `.cpp`。本轮未运行 cmake/ninja/测试二进制，
  覆盖率增量待主控全量复核。
