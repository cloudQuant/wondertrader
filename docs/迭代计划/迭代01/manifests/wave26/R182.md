## 3. 夹具与安全性

- 主存储读端复用 `q03_storage3_fixture.h` / `r52_storage_fixture.h` / `r74_rdm_fixture.h`：
  `q03::Sandbox` 切换到系统临时目录，析构恢复 cwd 并删除；`BDMgr` 提供生产语义
  `getBoundaryTime`；`r74::HotMgr` 提供可控切段（返回 false / 返回空 / 正常切段）。
- RDM RT 块按 `WtDataStorage/DataDefine.h` 的 `RTDayBlockHeader` 布局由 `make_rt_block` 落盘，
  读端只调公开虚接口；`init(NULL)` 不启动 5 秒巡检线程。
- AD 用例复用 `r162_ad_fixture.h`，数据全部由 `WtDataWriterAD::writeTick` 的公开路径落 LMDB，
  **不直写 `cache_m1.dmb`**（r172 的 RT 缓存直写用例在基线中 CRASH，`rc=139`，本 lane 避开）。
- 所有用例独立、确定性；无 300s sleep、无后台轮询线程；临时文件只写系统临时目录并在
  TearDown 清理。
