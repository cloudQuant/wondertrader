# 工作流清单模板

每个工作流提交 `docs/迭代计划/迭代01/manifests/<工作流>.md`，内容如下：

```markdown
# <工作流编号/名称> 测试清单

## 1. 范围
- 模块：
- 源文件：
- 测试目录：

## 2. 覆盖情况
- 已覆盖的公开 API/函数：
- 已覆盖的分支/边界：
- 未覆盖行及原因（外部依赖/平台/缺陷/待补）：

## 3. 测试清单
| 测试文件 | 测试用例数 | 覆盖目标 | 运行时长 |
|---|---:|---|---:|

## 4. 依赖与 mock
- fixture：
- fake SDK/服务：
- 临时目录/端口：

## 5. 缺陷
- 链接到 `bugs/<工作流>.md` 中的编号：
- 阻塞的覆盖率行：

## 6. 验证
- 语法检查命令：
- 主代理集成后的构建/测试结果：
```

## 验收
- 测试可在覆盖率构建中编译并运行；
- 目标模块行覆盖率达到 100%（已批准范围）；
- 未覆盖行均有原因；
- 不包含生产代码修改。
