## 3. 接缝与安全性

- 切片用例没有 `#define private public`、没有类布局镜像。`CtaStraBaseCtx.h:486/494`、
  `SelStraBaseCtx.h:436/445`、`HftStraBaseCtx.h:247/256/265/274/283` 本身就是 virtual；
  测试侧只继承公开的 `Exp*Context` 并 override，再用公开的 `Engine::addContext` 注入。
  切片由公开工厂 `WTSTickSlice::create` / `WTSOrdQueSlice::create` 等构造，回调同步消费。
- 故意不构造 `WTSTickSlice::create(code, NULL, 0)`：其 `_count` 在空构造路径未初始化
  （`WTSDataDef.hpp:1390-1429`），`size()` 会读未初始化值；空回调分支改用“非空切片 + tickCnt=0”。
- 不启动行情/交易/回放线程，不连接柜台，不写 shm/socket；只写系统临时目录并 `remove_all`。
- `TraderAdapter` 用例使用 q04 纯内存 `FakeTraderApi/FakeBaseDataMgr`，`run()` 只创建
  `_stat_map` 并记录 connect，不产生线程；生成目录指向临时目录。
- HFT 下单用例用公开 `TraderAdapter::initExt + run + onLoginResult`，避免 R124 同类用例
  未 run 时 `_stat_map` 为空导致的崩溃面。
