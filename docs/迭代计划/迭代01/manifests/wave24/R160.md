## 3. 夹具与安全性

- `r160_common.h`：二进制目录向上找插件、系统临时目录唯一子目录、临时切 CWD；
  `fs::remove_all` 在析构清理。
- EventNotifier 用例只建 `inproc://` 本地端点；端点名带 pid + 序号，避免冲突；
  WtMsgQue 缺失时 `GTEST_SKIP`，不访问网络。
- TraderAdapter 用例复用 `p11_wtcore_traderadapter/p11_trader_fixture.h` 的进程内
  `FakeTraderApi`/`FakeBaseDataMgr`/`RecordingSink`；只有模块装载用例真正 dlopen
  TraderMocker，且不调用 `run()`/`connect()`，不启动柜台线程。
- WtDtMgr/HFT 用例复用 `n02_wtcore_engines/r73_fixture.h` 的 bd/hot/engine 替身。
- 所有用例的临时文件只写系统临时目录（或 `./generated/traders/<id>`，沿用 P11
  fixture 的清理规则），不写仓库 `dist/`。
- HFT 的 run 用例是唯一的短线程：线程体内 sleep 10ms，`stop()` 前最多等 1 个
  周期；无 10 秒挂起（会话 00:00-03:59 保证闭合后 `isInTradingTime(0)` 仍为真）。
