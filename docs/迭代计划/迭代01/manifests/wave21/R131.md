## 6. 留白面及原因（均为既有缺陷/接缝，不重复立案）

1. **ExecMocker 整族**（`init` 插件段 71-85、`handle_init` 136-161、`_exec_unit` 的
   entrust/order/trade 270-335）：R111/R121 的插件用例在 `_exec_unit->init` 后崩溃
   （BUG-R111-001/BUG-R121-002），本轮不重试。试写的 `cancel(stdCode,...)` 用例需先把订单
   从 `_state=0` 激活，而激活必经 `handle_tick` 的 `_sink->handle_entrust`（会解引用空
   `_exec_unit`），故该用例未交付。
2. **Cta 策略回调**（968/1024/1034/1040、1238/1267）依赖真实策略插件，R121 的 Cta 插件用例
   日志停在 `[ RUN ]`；**hook 等待**（1138-1200、687）按约束不进入。
3. **Cta `dump_stradata/dump_chartdata` 的目录创建**（215/317）：`dump_outputs` 先创建同一
   目录，`handle_replay_done` 路径上恒不执行，属死行。
4. **Sel `_desprice!=0`**（368-369）、`do_set_position` 同量/空品种守卫（656/660）：
   `append_signal/do_set_position` 为 private，公开 `stra_set_position` 只能产生 `_desprice=0`
   且提前校验；比率滑点已由 R121 覆盖。
5. **Hft 插件/策略回调**（142-143、239-252、311、439-501、530、641-662）、`_ticks` 缓存
   （888-893，只 create/release 从不写入）、`splitVolume` 随机分支（68/98）。
6. **Uft `_strategy` 回调/会话**（62-64、154-167、206-213、225-390、804-825、1031-1047）：
   会话回调无判空（BUG-R121-001）、策略工厂未知名称崩溃（BUG-R111-001）。
   `CM_CoverToday` 下 `preavail` 分支（509-512、572-575、710-711、771-772）需要
   `on_session_begin` 把今仓滚成昨仓，而无策略时该入口即崩，暂不可达。
7. **HisDataReplayer 私有 bin/loader 分支**（3190/3306-3322/3446-4360 等）需要 `HisDataMgr`
   动态库与真实 dsb 数据；`run_by_tasks` 日频分支里的 `case TPT_Minute`（985）位于
   `_period != TPT_Minute` 内，属不可达死代码。
