## 5. 统计口径说明（不是缺陷）

- `StateMonitor.h` 的 `isAnyInState/isAllInState/isInState` 与 `WtBtRunner.h` 的
  accessor/event inline 函数在 `llvm-cov show` 中恒为 0，尽管 r145/r143 与本轮
  用例确实调用且 PASS（导出的 function record 只有一条 count=0）。原因是这些
  类体内联函数在 -O0 下被内联进调用方 TU，行归属落在调用方文件；因此这 85 行
  无法通过“再写用例”变为 covered。建议主控在汇总时按“口径不可达”单列，不要
  计入 90% 目标的分母（或改用 `-fno-inline-functions` 重编测试目标后复核）。
  为验证该判断，本轮检查了 `llvm-cov show -show-instantiations` 与
  `llvm-cov export` 的 function record，均只有一条 0-count 记录。
