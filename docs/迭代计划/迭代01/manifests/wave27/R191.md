## 3. 夹具与安全性

- `r191_common.h` 只读复用 `p08/r111_common.h`（插件路径、TickLoader）与
  `p08/r62_mocker_common.h`（真实 `HisDataReplayer`、csv 日线、系统临时目录），
  新增 `make_uft_cfg` / `make_cta_cfg` 两个最小合法插件配置。
- 所有临时文件只落 `temp_directory_path()/r62_*`，TearDown `remove_all`；
  不联网、不启动线程、不 sleep、不读挂钟。
- 只走公开 API：`init_*_factory/handle_init/handle_* /on_trade/on_order/on_entrust/
  on_channel_ready/on_calculate/stra_*`。无 `#define private public`、
  无类布局镜像、无宏改写。
- 插件用例（#1/#2/#3）用 `new` 创建 Mocker 后**故意不 delete**：真实插件工厂的
  `_StraFactInfo` 析构调用 `_remover(_fact)` 会 SIGSEGV（R121 的
  `R135ProbeMinimalDtor`/`R135ProbeStrategyNoCalls`/`PluginStrategyLifecycle` 日志均
  在作用域结束时崩溃）。不 delete 是为了让进程正常退出并留下 profraw；
  断言未放宽，缺陷另立 BUG-R191-001 并加 `DISABLED_` 复现占位。
- `UftMocker::procTask` 是 private，公开路径中只有 `on_tick` 会排空任务队列；
  #2 用策略不关注的 kCu tick 驱动 entrust/cancel 任务，不触碰 kStk 撮合。
- `CtaMocker` 插件用例策略 code=kAg（无 csv），`on_init/on_calculate` 在
  `stra_get_bars` 返回 NULL 后早退；不调用 `handle_schedule/step_calc/install_hook`，
  避开 R111/R121 的线程等待与空指针崩溃面。
- 语法门禁：新增内容先写 `r191_mocker_residual_test.cpp.tmp`；因门禁脚本按 `.cpp` 后缀
  识别源码，用同内容 `.cpp` 副本执行 `gate_flags/CoverageTests_btcore.sh` 得到 rc=0，
  随后删除副本并把 `.tmp` 改名为 `.cpp`（最终 `.cpp` 再跑一次 rc=0）。
