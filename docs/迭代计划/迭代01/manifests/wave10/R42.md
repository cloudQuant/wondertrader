## 3. 未覆盖面与原因（本 lane 口径）

| 位置 | 未覆盖原因 |
|---|---|
| `CtaStraBaseCtx::stra_get_bars/stra_get_ticks/stra_get_last_tick` | 裸 `WtCtaEngine` 的 `_data_mgr == NULL`，调用即空指针；需要 WtDtMgr 成功初始化（需真实 WtDataStorage 插件） |
| `CtaStraBaseCtx::do_set_position` 的 `_slippage != 0` 分支 | 走该分支需要非零滑点且由信号进入；为保持既有 p01 夹具一致，本轮统一 slippage=0 |
| `CtaStraBaseCtx::on_tick` 的 `sigtype==0` 调度信号分支 | 需要主 K 线闭合后由 `on_schedule` 内的 `stra_enter_long` 产生信号，再由 tick 触发；涉及 WtDtMgr 历史数据 |
| `HftStraBaseCtx` 的 `stra_buy/sell/enter/exit/get_position/...` | 全部要求 `TraderAdapter`（真实 trader 插件），任务令禁止连接柜台 |
| `WtDtMgr` 的成功 reader 分支（L84-86、L180-217 缓存、L277-376 后复权切片） | 需真实 `WtDataStorage` 插件；`IDataReaderSink` 的缓存需 reader 回灌 |
| `WtDtMgr::on_all_bar_updated` 的非空通知队列 | 需要已订阅基础 K 线，唯一入口在 `get_kline_slice`（reader 非空） |
| `ParserAdapter::init` 的插件成功段与 filter 段（L127-212） | 需真实 parser 插件 dylib；filter 是 `init` 私有路径，`initExt` 无 filter 入参 |
| `WtLocalExecuter/WtArbiExecuter/WtDiffExecuter` 明细拆单 | `ExecuteUnit` 只能由插件工厂反射创建；p02 既有用例已覆盖可注入面 |
| `SelStraBaseCtx::stra_get_bars/get_ticks/get_last_tick` | 同 CTA，需成功 WtDtMgr |
| `SelStraBaseCtx::stra_get_day_price` | 引擎 `_data_mgr == NULL` 时 `WtEngine::get_day_price` 解引用空指针 |
