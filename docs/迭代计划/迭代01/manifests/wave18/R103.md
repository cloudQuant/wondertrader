## 1. 范围与思路

R43/R67/R72/R80/R91 已覆盖 HisDataReplayer 的 loader 接缝、日/分钟回放、任务日历、
bin 存储、复权与 Level2；R60/T6 已覆盖 TraderMocker 的 connect/查询/报单撤单与未知 UDP 头。
本轮只补它们未触达、且仍能从公开 API 进入的剩余行段：

- HisDataReplayer：
  - loader `isAutoTrans` 的落盘/回读（含 ruleTag 复权文件名、m5 BlockType）；
  - loader 抛异常的两个 catch、`cacheRawBarsFromBin` 的 raw loader 臂、
    `cacheAdjustedStkBarsFromBin` 的分钟/loader/空块分支；
  - integrated 主力连续的**分钟线**主段+分月段合并（含后复权）；
  - 分钟/日线切片的后置 cursor 前进、未订阅合约的 cursor 跳过、`get_day_price` 的 `_day_cache`；
  - 任务日历的月频精确/同月顺延、年频、周频补发、分钟起点修正；
  - csv tick 的 RAW_V2 直通与 `etime` 落在两笔之间的回退；
  - `store` 配置与缺失复权因子文件。
- TraderMocker：
  - `load_positions` 的 JSON 解析失败；
  - 无 listener 时 `write_log(NULL)` 与撤单守卫、报单落盘；
  - 空头平仓冻结/撤单释放；
  - UDP 空数据报早退、未知包头、合法 tick 包与析构 `_ticks` 释放。

只走公开 API；不使用 `#define private public`、不镜像 TraderMocker 私有布局、不改宏；
不碰 TraderMocker 私有 `match_once`，不调 `login()`，不碰 HisDataReplayer `_listener` 空指针崩溃面。

## 3. 留白面及原因

1. `notify_state` / `EventNotifier`（`557-591`、`667`、`730`、`768`、`924`、`1097`、`1235`）：
   需要 WtMsgQue 服务端线程，按本轮约束不接真实服务。
2. TraderMocker 私有 `match_once`（`328-514`）、`login`/`match` 线程（`723-743`）：
   lane 明令不碰；`splitVolume` 的 `curVol==0` 分支也只在其中可达。
3. TraderMocker `handle_read` 的 socket error/reconn 分支（`937-948`、`666-673`）：
   需要真实 socket 故障注入，本轮不制造。
4. HisDataReplayer `_listener` 为空、空 CSV 越界、未知会话 NULL 等崩溃面（p04/R20/R43/R67/R80 已登记）：
   不重复、不造崩溃用例。
5. `cacheRawTicksFromBin` 的 HOT tick 文件臂（`3306-3322`）：需要 ruleTag + bin tick 组合；
   本轮 tick 走 csv dsb，未叠加。
6. `proc_block_data` 的压缩尺寸校验/老版本保留块头臂（`69-72`、`80-85`、`126-135`）：
   需要构造畸形/老版本块，且与既有 R72 老版本覆盖重叠，未重复。
7. `get_kline_slice` 重采样失败（`2321-2325`）与 `kBlkPair==NULL`（`2330-2332`）：
   未找到确定性触发输入（`extractKlineData` 返回 NULL 的条件依赖数据形态）。
8. `run_by_tasks` 的夜盘 offset 分支（`1174-1187`）与 24h session 换日：
   为避免交易日/时间轴回绕造成长循环，本轮不硬闯；R80 已覆盖白盘分支。
9. `getNext*Time` 的收盘过滤/游标 while（`1608-1614`）与 `replayHftDatas` 的
   `cursor>count` 空转（`1930`、`1972`、`1994`）：R91 已覆盖主路径，本轮不重复。
