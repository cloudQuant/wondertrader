## 2. 覆盖策略

- 逐笔/tick 的跨自然日样本统一按 `(action_date, action_time)` 升序构造：
  - RT 用例：前一日 21:00 + 当日 09:30 + 当日 10:30，截止 10:00；
  - 历史用例：前两日 21:00 + 历史日 09:30 + 10:30，避免首条即晚于 eTick 触发
    `pItem--` 无守卫（BUG-R100-002）。
- 短文件 / 空载荷（CMP_V2 空 payload）二次访问用于命中原文件缓存里 `_block == NULL` 与
  `tcnt == 0` 的守卫；每种数据类型使用不同合约代码，绕开 `_his_ordque_map` 共用键缺陷。
- AD 读取器：`WtLMDB` 同一 (交易所, 周期) 的第 3 次 `get_k_db` 会拿到被 `std::move` 掏空的
  句柄（R4-BUG-02），因此 onMinuteEnd 用例刻意让 `readKlineSlice` 只做一次取库
  （末条不早于 etime），把第二次取库留给 `onMinuteEnd`；`cacheBar 晚于 etime` 的二次回源
  分支（:451-456）与 `update_cache_from_lmdb` 的新 bar 追加（:292-297）因此留白。
- AD 写入器：预写 `cache_m1/m5/d1.dmb`（capacity=2,size=2）后写第 3 个合约触发扩容；
  RT 缓存条目通过 `BoostMappingFile` 可写映射原地推进，模拟 writer 侧更新。
