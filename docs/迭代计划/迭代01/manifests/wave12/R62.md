## 3. 留白面及原因

1. **Uft `on_session_begin/on_session_end`、`stra_enum_position`**：源码无条件解引用 `_strategy`（`UftMocker.cpp:343-390、1030-1047`），无策略必崩，已由 `BUG-P08-001` 登记；本 lane 不重复，也不再写阻塞性用例。
2. **Uft/Hft `procOrder` 的成交段**：需要 `HisDataReplayer` 的 tick 缓存返回非空 `WTSTickData*`，仓库无可只读复用的 tick 数据集；本 lane 覆盖到 `stra_get_last_tick==NULL` 的早退和订单循环，成交回写改用 public `on_trade` 注入（p08 同口径）。
3. **Cta 图表指标/打点的调度期正路径**：`add_chart_mark`/`set_index_value` 要求 `_is_in_schedule==true`，只有策略回调能在调度期内调用；不加载策略 DLL 时不可达。R43 已覆盖调度期外的拒绝分支与 `dump_chartdata` 结构。
4. **Sel `handle_replay_done` 零调度**：`_total_calc_time / _emit_times` 除零（`BUG-R43-001`）；本 lane 的落盘用例都先调度一次，零调度场景不重复。
5. **Cta/Hft `install_hook` + `step_tick/step_calc` 的同步等待**：`_has_hook` 为真时忙等/条件变量会阻塞单线程测试（p08 已整族 DISABLED），本 lane 不触碰。
6. **策略工厂成功加载/策略回调**：需要真实策略 DLL，禁止加载；只覆盖模块缺失失败分支。
7. **Cta 条件单的 `WCT_Equal`/`WCT_Smaller`/`WCT_Larger` 由 load_incremental_data 构造的 JSON 条件覆盖（Equal/SP）；公开 `stra_*` 只能构造 LargerOrEqual/SmallerOrEqual，故其余比较符只通过 JSON 条件覆盖，不额外造私有 map。**
8. **空头 `stra_get_position_avgpx`**：仓库既有口径为「有符号均价」（q02 清单已固化 -61/-10），本 lane 不重复断言，也不按缺陷登记。
