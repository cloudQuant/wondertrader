## 0. 本轮选择的公开接缝（与 T6 的口径差异，先说清楚）

T6 的结论是「orderInsert/orderAction/query* 的 lambda 体只有 io_context 被 run 才执行，而 run 的唯一
公开路径是 connect()/login() 的线程」，因此 T6 把这些面整块留白。本轮不碰私有 `match_once()`，
只调用 **公开的 `connect()`**（不调 `login()`、不进入撮合线程）：

- `connect()` 的副作用：`reconn_udp()` 在 `0.0.0.0:<udp_port>` 上 open/bind（除 UDP 用例外 `udp_port=0`
  由系统分配临时端口），再起一个 `io_context::run` worker，post `load_positions()+handleEvent(WTE_Connect)`。
  这是本地回环/临时端口，不连外网、不连真实柜台；worker 在 `release()` 里被 `stop()+join()`。
- 这使 `orderInsert/orderAction/queryAccount/queryPositions/queryOrders/queryTrades` 的 lambda 体、
  `load_positions/save_positions`、`handle_read/extract_buffer`（仅未知包头分支）第一次可从公开 API 到达。
- 等待全部是 3s 上限内、2ms 间隔的短轮询；不用固定长 sleep 猜时序。唯一 50ms 等待用于让
  loopback UDP 包先于后续查询被 io 线程处理，属有界短等待。
- `match_once()`/撮合价量、`_awaits/_positions` 私有状态仍不硬闯；`login()` 的撮合线程不启动。

## 4. 留白面及原因（未硬闯）

1. **TraderMocker `match_once()` L328-514**：私有 + 依赖 `_ticks/_awaits/_positions`，且 lane 明令
   「不硬闯」；`login()` 会起 5ms 撮合循环。T6-001/011 已记录其内部 `VolTraded` 递减缺陷。
2. **TraderMocker UDP tick 分支 L997-1006**：需要按 `WTSTickStruct` 的二进制布局构造包头+包体；
   该结构只在 .cpp 内定义，测试侧重镜像布局属禁止的「类布局镜像」，故只测未知 `_type`。
3. **TraderMocker `handle_read` 错误分支 L937-948**：需要让 socket 进入 error_code 且 `_terminated=false`，
   只能在真实 socket 故障下稳定触发；本轮不注入。
4. **TraderMocker 空指针崩溃面**：`init(NULL)`（T6-008）、`orderInsert` 在 `ct==NULL` 且 `_bd_mgr==NULL`、
   `commInfo==NULL`、`orderAction(NULL)`（BUG-R60-007）、先撤单后建 `_awaits`（BUG-R60-002）均不执行。
5. **TraderYD `connect/doLogin/notifyLogin(成功)/notifyFinishInit`**：本机 `m_funcCreator/m_pUserAPI`
   恒 NULL，调用即崩；`DISABLED_connect...` 只留钩子。
6. **TraderYD 订单/成交的非开仓缓存分支**：`m_mapPosition` 只在 `notifyFinishInit`（不可达）里创建；
   `notifyOrder` 平仓或 `notifyTrade` 任意合约都会在 L447/L551 空指针解引用（BUG-R60-005 / T5-15）。
7. **TraderYD orderInsert/orderAction/query 的发送体**：都要求 `WS_ALLREADY` 且 `m_pUserAPI != NULL`；
   本机无法构造厂商 API 实例，故只有守卫/参数校验面（T5 已覆盖）。
8. **TraderYD `notifyAccount` 的字段更新体 L626-638**：`m_ayFunds` 只在 `notifyFinishInit` 里创建，
   本机不可达；T5 已覆盖两条空守卫。

## 5. 构建/运行副作用

- 每个 Mocker 用例在系统临时目录（`temp_directory_path()/wondertrader_r60_mocker_<pid>_<seq>`）下运行，
  `init` 生成的 `mocker_<id>/positions.json` 随 fixture 析构 `remove_all` 清理；不落仓库。
- 每个 Mocker 用例 `connect()` 起一个 io worker 并 bind 一个本机 UDP 端口（前 7 条为 0→临时端口，
  UDP 用例先取一个空闲回环端口），`release()` stop+join；不访问外网/真实柜台。
- YD 用例不建文件、不起线程（`DISABLED_connect` 不运行）。
