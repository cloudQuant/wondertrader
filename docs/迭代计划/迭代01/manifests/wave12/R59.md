## 4. 留白面及原因

1. **执行单元（ExecuteUnit）非空的分支**：`_unit_map` 是 private，唯一入口
   `WtExecuterFactory::createExeUnit/createDiffExeUnit` 需要 dlopen 执行器插件 dylib；
   `CoverageTests_wtcore` 不加载任何插件，`unit` 恒为 NULL。因此三个执行器的
   `set_position/on_tick/on_trade/on_order/on_entrust/on_channel_*` 中所有
   `unit->self()->...` 转发与拆单/追单本体仍不可达（p02 已记录同一边界）。
2. **TraderAdapter::init 的模块装载段（:166-206）**：交易插件是 SHARED+hidden，只能 dlopen；
   本 lane 只覆盖 module 为空的早退（并通过它把 `_cfg` 落地，驱动 WTE_Connect 登录分支）。
3. **风控频率窗口（:566-593 / :631-658）**：p11 已实测时间缓存按交易所原始代码写、
   检查按标准代码读，窗口分支不可达（BUG-P11-003），本 lane 不重复。
4. **EventNotifier 分支**：`_notifier` 需要 libwtpy + MQ server，本 lane 一律传 NULL。
5. **cancel 的 `_cancel_time_cache` 实体窗口**：同 3，受键不一致限制。
6. **买/卖中 cInfo==NULL 且 getContract 失败的路径**：会让 `cInfo->getAltCode()` 解引用空指针，
   属已知崩溃类（BUG-P11-002 同族），未放进启用用例。
