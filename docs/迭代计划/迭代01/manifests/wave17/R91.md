## 1. 范围与思路

R43/R67/R72/R80 已吃掉 loader 接缝、回放任务、日线/分钟 CSV、切片/dump 面；
本轮只补它们没有触达的公开面，且全部通过 `init(cfg)`（`mode=bin`）让
`HisDataMgr` 调起已链接进测试二进制的 `WtDataStorage` 读取器，从临时 `.dsb` 目录装数：

- `cacheRawBarsFromBin` 正常日线装载与失败 NULL 切片（L4484-L4605）；
- `cacheAdjustedStkBarsFromBin` 前/后复权、复权段缺失、无因子分支（L4236-L4481）；
- `getAdjFactors` 通过 `IBtDataLoader::loadAdjFactors` 按需取因子（L4192-L4234）；
- `cacheIntegratedFutBarsFromBin` custom rule（HOT）主段 + 分月段合并/复权（L3900-L4190）；
- `cacheRawTicks/OrdDtl/OrdQue/TransFromBin` 与 `get_order_*_slice` 有数据臂
  （L3299-L3441、L2470-L2689、L2702-L2826）；
- `getNext*Time` 的两种初始化游标（`UINT64_MAX` / 指定 `stime`）（L1536-L1767）；
- `replayHftDatas` / `replayHftDatasByDay` 四类数据回放（L1769-L2011）；
- `run_by_ticks` 的 session/交易日推进、`run_by_bars` 的 tick 窗口回放（L741-L769、L853-L858）；
- `get_day_price`/`get_cur_price`、reset/clear_cache、空输入与费率默认分支
  （L3034-L3087、L459-L516、L436-L457、L2828-L3019）。

只走公开 API；不使用 `#define private public`、不镜像类布局、不改宏；
不碰私有 bin/cache*FromBin 声明与 `_listener` 空指针崩溃面。

## 3. 留白面及原因

1. `cacheIntegratedFutBarsFromBin` 的**分钟线**分支（L4016-L4034）与 `eIdx < sIdx`
   / 加载失败分支：本轮只构造日线主段+分月段夹具；分钟边界需
   `getBoundaryTime` + 交易时段对齐，且与日线分支只差 `time` 字段，留待后续。
2. `cacheRawBarsFromBin` 的 loader 分支（L4527-L4534）：R2 已覆盖，本轮不重复；
   本 lane 的 loader 只提供复权因子，K线刻意走存储目录。
3. `cacheRawTicksFromCSV` 的 CSV 解析段（L3511-L3584）是注释掉的死代码，LLVM 不计行。
4. `notify_state` / `EventNotifier`（L557-L591）：需要 MQ server 线程，按计划不接真实服务。
5. `_listener` 为空、空 CSV 越界、未知会话 NULL、`HisDataMgr` 装载失败空 `_reader`
   等已知崩溃面（p04/R20/R43/R67/R80 已登记），本轮不重复、不造崩溃用例。
6. `check_cache_days`（L4607-L4634）：R67 已覆盖淘汰分支，本轮 `cache_clear_days=0` 规避。
7. `simTickWithUnsubBars` 日线分支的 NULL commodity 崩溃（BUG-R67-002）与
   loader 成功但 0 行（BUG-R67-001）保持既有归档。
