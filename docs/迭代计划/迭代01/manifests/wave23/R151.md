## 3. 夹具与安全性

- `r151_common.h`：仓库根探测（`dist/common/sessions.json`）、系统临时目录、bar CSV 写入、
  csv 回放配置（commodities + stk_comms + sessions + holidays + fees）、IDataSink 记录器。
- Hft/Uft 用例使用 `r111::TickLoader` + `r111::make_tick_cfg`，`stime=20200102 09:30`、
  首笔 tick=09:31。**刻意把起点放在首笔之前**：若起点晚于最后一笔，会触发
  `HisDataReplayer::get_last_tick` 的越界读（BUG-R103-002），r111 的 Hft 用例即在
  此处 `[ RUN ]` 后中断。
- Cta/Sel 比率滑点使用 `r62::ReplayFixture`（真实 csv 日线 + 公开 `handle_tick`），
  不加载策略/执行器插件。
- 不启动线程、不读挂钟、不 sleep；临时目录全部由 TearDown `remove_all`。
