## 3. 夹具与安全性

- 复用只读夹具 `p08/r191_common.h`（Uft/Cta 插件配置、`r111::plugin_path`）与
  `p08/r121_common.h`（`NullSink`、`make_module_cfg`）；无新增头文件。
- 所有临时文件只落 `temp_directory_path()/r62_*`，`TearDown` 清理；不联网、不起线程、
  不 sleep、不读挂钟。
- 用例 2 的 `prepare()` 只注册 `NullSink`，不把 Mocker 挂成 listener；平今与零量
  直接走公开 `IDataSink::on_trade`，不依赖撮合线程。
- 插件用例（#3/#4）与 #6 的工厂对象用 `new` 创建后**故意不 delete**：本机构建的
  插件工厂析构会在 `_StraFactInfo::~_StraFactInfo` 调 `_remover` 时 SIGSEGV
  （BUG-R191-001）。断言未放宽。
- 只走公开 API：`init_*_factory/on_trade/handle_session_*/handle_replay_done/
  stra_*`。无 `#define private public`、无类布局镜像、无宏改写。
- #6 的 module 优先找 `libWtHftStraFact.dylib`；本机构建无此产物时退回同
  `createStrategyFact/deleteStrategyFact` C ABI 的 `libWtCtaStraFact.dylib`。
  配置**无 `strategy` 段**，不创建策略、不解引用错误类型的工厂指针，且整对象泄漏，
  因此不会进入任何 HftStrategy 虚调用或工厂析构。
