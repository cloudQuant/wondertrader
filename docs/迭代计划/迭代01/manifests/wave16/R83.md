## 4. 运行安全设计

1. **单例隔离**：`coverage.sh` 为每条用例起单独进程；为兼容「整个二进制一次跑完」，
   CTA/SEL 用例在 `TearDown` 中显式调用 `WtBtRunner` 的公开析构 + placement new，
   把 `_cta_mocker`/`_sel_mocker` 还原为 NULL、`_async` 还原为 false。后序
   `R9Wired.MockersAreNullAndAsyncFalseBeforeInit` 的断言仍成立。
2. **HFT 不碰父进程单例**：`_hft_mocker` 未进构造初始化列表（BUG-R46-001/Q06-003），
   无法用同样方式还原；两条 HFT 用例在 `fork()` 子进程中初始化并调用，子进程
   `exit()` 时落 profraw（`%p` 保证与父进程文件不同），父进程只读取管道结果并断言
   `getRunner().hft_mocker() == nullptr`。
3. **无回测/线程/落盘**：所有 mocker 均以 `persistData=false` 创建，不调用
   `run/release/config`；HFT 的 `postTask` 只入队不执行；临时文件为零。
4. **确定性**：空簿 map 查找、空切片、空枚举、非异步 step 的返回值都可由实现推出；
   不依赖墙钟、随机数、网络或跨用例状态。

## 7. 留白面及原因

| 未覆盖 | 原因 |
|---|---|
| `cta_get_bars`/`cta_get_ticks`/`sel_get_*`/`hft_get_*` 的「切片非空」回调体 | 需要 basefiles（商品/交易时段）+ 外部 bar/tick loader 才能让 `get_kline_slice` 通过 session 校验；本轮只取空切片支，避免把单例回放器配置成半初始化状态 |
| `cta_get_all_position`/`sel_get_all_position` 的枚举 lambda 体 | 需要非空 `_pos_map`/`_sig_map`，只能由真实撮合或受保护的 `on_tick_updated` 写入；C API 无直接建仓入口 |
| `add_chart_mark` 写入与 `set_index_value` 成功支 | 两者都要求 `_is_in_schedule==true`，只能由回放调度置位 |
| `cta_step`/`hft_step` 的异步支 | 要求 `run(..., bAsync=true)` 已置 `_async`，属完整回测面 |
| `*_save_userdata` 的**磁盘落盘** | C 导出的 save 只写 mocker 内存 map（`_ud_modified`）；`dump_outputs()` 要到 `on_bactest_end` 才写 `ud_<name>.json`/日志 csv，需完整回测 |
| `WtBtRunner::run` / `stop` 运行中 / `release` / `_inited` | 需真实回放器 prepare/run/线程 join；`release` 的 `WTSLogger::stop` 会进程级静音（同 BUG-R6-006 裁定）；`_inited` 全仓库无置位点（BUG-R9-002） |
| `init_hft_mocker` 在父进程单例上调用 | 会永久写非空且无公开复位入口，破坏 R9 的前置断言；改在 fork 子进程取同一批行 |
| `init_sel_mocker` 的 NULL/超长模板参数 | 崩溃/越界类，只登记 BUG-R83-001，DISABLED 占位 |
