## 4. 未覆盖面及原因

1. **`CtaStraBaseCtx.cpp:1423-1425` 品种缺失早退**：`do_set_position` 为 private，只能由 `on_tick` 信号分支调用；而信号分支前先 `_engine->get_session_info(code, true)`，未注册品种返回 NULL 后立即解引用（既有崩溃面 BUG-P01-001 系），因此公有 API 无法安全到达该 return。
2. **`CtaStraBaseCtx.cpp:916` 条件动作 default**：非法 `action` 在 `load_data` 恢复时先被 `ACTION_NAMES[action]` 下标访问；命中后 `on_tick` 日志同样索引 `ACTION_NAMES`。非法值属越界读，不能作为正常测试输入（见 BUG-R81-002）。
3. **`HftStraBaseCtx.cpp:691` 价格缓存命中**：`HftStraBaseCtx::_price_map` 在整份实现中没有任何写入点，该分支为死代码（BUG-R81-001）。
4. **`HftStraBaseCtx.cpp:846` 零手明细 continue**：`_details` 只在 `do_set_position` 中新增/消费，消费时会同步删除零手明细；Hft 无 `load_data`，公有路径无法构造“已存在的零手明细”，属防御性死分支。
5. `HftStraBaseCtx.cpp` 其余少量 report 行（report 31 vs 当前 profile 27）为 profdata 与 report 时间差导致，已按当前 profile 清零；`stra_get_bars/ticks/L2` 等切片面由 R71/Q01 既有用例覆盖，本 lane 不重复。
