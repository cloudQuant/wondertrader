## 4. 未覆盖面及原因（延续既有结论，不重复开单）

1. **EventNotifier JSON/广播（约 110 行）**：只能经 `_mq_sid != 0` 的 asio 任务进入；`init` 成功要真的
   `dlopen WtMsgQue` + `create_server`，且会起 2ms 休眠的 worker。`tradeToJson/orderToJson` 还是 private。
   `WtHelper::getCWD()` 是进程级静态缓存，无法在不影响其他用例的前提下把模块查找指向临时目录。
   沿用 BUG-R11-006（接缝缺失）。
2. **ShareManager 已初始化后的读写/监控（约 150 行）**：`_inited` 只能由成功装载 WtShareHelper 置真，
   随后即真实共享内存。沿用 BUG-R11-001。本波只补了「文件存在但不可装载」的 25 行。
3. **UftStraContext 的 `read_param/sync_param` 数值重载（705-727）**：`allocate_value` 返回 nullptr 被直接
   解引用（BUG-R11-002）；`stra_get_bars/ticks/order_detail/order_queue/transaction` 的 `sub_*` 行
   （944-982）需要引擎返回非空切片，UFT 侧无数据注入点（BUG-R11-005 同类）。
4. **TraderAdapter 频率风控（1878-1902、1940-1965）**：时间缓存写入语句在产品里被注释，属死代码
   （BUG-Q04-004）；`getRiskParams` 缺 default 时对 `end()` 取址（BUG-R11-003），因此
   `riskPara==NULL` 的 1864/1926 不可达；`isTradeEnabled` 只有 `inline` 声明（BUG-Q04-006），外部 TU 不可链接。
5. **WtUftTicker 自动收市/跨零点/非交易时段分支（205-247）**：需要墙钟推进或落进 10s 休眠，确定性不足。
6. **WtDataManager 的非空缓存/实时 K 线与区间读（约 270 行）**：`IRdmDtReader` 由插件唯一创建，AD reader 的
   byCount/byDate 是 TODO NULL，WtDataStorage reader 的 `init` 无条件起 5s 巡检线程；AD 空库区间读会越界
   （BUG-R45-003）。无注入点（BUG-R8-003 / BUG-Q05-001）。
7. **WtDtServo.cpp 导出层「有数据」的 71 行**：需要全局 `getRunner()` 成功初始化且切片非空；全局 runner 一旦
   初始化会污染 r45 对未初始化态的断言（用例间依赖执行顺序），故不启用。
8. **WtDtServo ParserAdapter 的 createParser 返回 NULL（129-132）与 api->init 失败（192-195）**：构建产物里
   没有「导出入口但返回 NULL」的插件，`ParserUDP::init` 恒为 true；不伪造插件。
9. **WtUftCore ParserAdapter 的 createParser 返回 NULL（89-93）与 init 失败（153-156）**：同上，无可驱动插件。
10. **WtDataManager 的默认模块名（56）与缺符号日志（64-72）**：前者要继续走到 `WtDataStorage` reader 的 5s 巡检线程，
    后者紧接着 `_reader->init` 会空指针（BUG-R8-002）；`get_session_info(sid, isCode=false)`（148）是私有函数且所有
    调用点都传 true，属死代码。

## 6. 运行时前置条件与风险

- 两个测试体与产品插件同在 `build-cov/build_x64/Debug/bin/`；用例用 `dladdr` 从可执行体路径推出该目录。
- `libTraderMocker.dylib` / `libParserUDP.dylib` / `libWtDataStorageAD.dylib` 缺失时对应用例 `GTEST_SKIP`。
- ticker 用例只起一个线程，`(0,100)+(100,2400)` 两段拼接时段使其在除 00:00/01:00 外的任何墙钟都走 10ms 休眠分支
  （恰在这两分钟启动会落进 10s 分支，概率极低且不影响断言）；sleep 40ms 后 stop/join。
- `TraderAdapter` 用例临时改进程 CWD 并复原；`WtHelper::setInstDir` / `WtDtServo::WtHelper::set_module_dir`
  用后复位（传空串）。
- 所有临时目录在 `fs::temp_directory_path()` 下，TearDown/析构 `remove_all`。
