## 1. 范围与思路

R72 已补 tick loader 面与老版本块；R67/p07 补了 loader 回放、分钟重采样、任务调度基础分支。
本轮只补仍可见的公开 API 缺口：

- `run_by_tasks` 的节假日/周末回溯与月度顺延分支（L940-L1102）；
- 带已订阅 K 线的分钟任务回放（L1104-L1240 + `simTicks`/`onMinuteEnd` 分钟臂）；
- `get_kline_slice` 首次定位落在「未来首根」时的 `_cursor=0` 分支（L2384-L2387、L2458）；
- CSV 未订阅品种（`cacheRawBarsFromCSV` 的 `bSubbed=false`）与 `checkUnbars`（L3167-L3257）；
- `simTickWithUnsubBars` 分钟臂（L1389-L1463）；
- `get_day_price` 的 `_day_cache` 分支（L3068-L3087）；
- 期货 ruleTag 的 CSV/dsb 命名臂（L3762-L3771）；
- 合约数组装载、坏 fees 文件、除权因子非数组条目（L251-L265、L2946-L2962、L362）；
- `dump_btstate` 的 m1/m5 周期命名（L518-L555）；
- 逐 tick 回放下的 Level2 空缓存循环、`sub_*` 复权后缀与 reset 游标（L1626-L1768、
  L1795-L1898、L3089-L3165、L462-L466）。

只走公开 API；不使用 `#define private public`、不镜像类布局、不改宏；不碰 bin/cache*FromBin
与 `_listener` 空指针崩溃面。
